# Workspace Overhaul, Plan 4 of 4 — Deploy — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put the OTH map editor on Railway tonight, behind a shared team code, with the team's local work carried over intact, a smoke test that proves the paths that matter, and a one-page note for teammates.

**Architecture:** The server gains a team-code gate: middleware in front of every route except `/api/health` and the gate's own form, a self-contained team-code page served by the server, and an HMAC cookie. The editor reloads to that page if its cookie stops working. Three production hazards are fixed: the pg pool's unhandled `error` event, 500 bodies that leak `err.message`, and storage paths written with Windows backslashes. Two CLI commands, `data:export` and `data:import`, move every row and every file from one server to another, all-or-nothing, into an empty database only. Railway builds one Docker image. Postgres comes in through `DATABASE_URL`, and a volume is mounted at `/data`. The smoke test is Playwright, run by hand. The last task is a runbook the controller follows, not an implementation task.

**Tech Stack:** Node 24, Hono, Drizzle (Postgres on Railway, PGlite locally and in tests), `pg`, `sharp`, React 18 editor built by Vite, Vitest 1.6, `@playwright/test` 1.63.0 (new, dev only), Docker, Railway CLI 5.26.

## Review Focus

1. **Windows paths in the data.** Every `storage_path` written on the laptop reads `assets\8b\8b0c…jpg`. Checked on a copy of the dev DB on 2026-09-28. On Linux none of those files would be found, so every frame, plan and model would fail to load in production. Export must write forward slashes, new uploads must too, and readers must accept either. Pinned in Task 3 (`storeAsset`, `assetFile`) and Task 4 (the round trip reads a frame whose row was written with backslashes).
2. **A second import, or an import into a server someone has started using**, must refuse and write nothing: no merge, no duplicates. An import that stops partway (a missing file, a failed row) must leave the database empty, so it can simply be run again. Pinned in Task 4.
3. **Someone guessing the team code, or a crafted link through the gate.**
   - Wrong codes are limited, and while the limit is reached even the right code waits, so a guess can never be confirmed.
   - The page you return to after the gate is always on this site.
   - The return path is escaped wherever it is written back into the page.
   Pinned in Task 1.
4. **A browser whose gate cookie stops working mid-session** (the code was changed) must go back to the team-code page. It must not get a sign-in dialog that refuses every name. Pinned in Task 2, on the client and on the reload guard.
5. **The smoke test run against the team's live server.** It must leave nothing behind and never publish. That holds if it fails halfway too, and if its click misses the test area. Pinned in Task 6 (cleanup by stamp, a last test that checks it, and a Publish it refuses to press unless blocked).

### Task 1: The team code gate

**Files:**
- Create: `packages/server/src/gate/gate.ts`, `packages/server/src/gate/page.ts`
- Modify: `packages/server/src/config.ts`, `packages/server/src/app.ts`, `packages/server/src/index.ts`
- Test: `packages/server/src/gate/gate.test.ts` (create), `packages/server/src/config.test.ts` (create)

**Runs beside Plan 3:** yes. Server files only.

**Interfaces:**
- Produces:
  - `loadConfig(env).TEAM_CODE: string | undefined`: trimmed, and blank reads as unset.
  - `teamCodeProblem(config: Config): string | null` (`config.ts`).
  - `MIN_TEAM_CODE_LENGTH = 8`.
  - `teamGate(code: string, options: { secure: boolean; now?: () => number }): { guard: MiddlewareHandler; routes: Hono<AppEnv> }` (`gate/gate.ts`).
  - Also from `gate/gate.ts`:
    - `GATE_COOKIE = "oth_gate"`;
    - `gateToken(code): string`;
    - `codeMatches(typed, code): boolean`;
    - `safeNext(raw): string`;
    - `WrongCodes`;
    - `WRONG_CODE_LIMIT = { max: 20, windowMs: 900_000 }`;
    - `WRONG_CODE`, `TOO_MANY`;
    - `GATE_REFUSAL = { error, gate: true }`.
  - `AppDeps.teamCode?: string | null`. When it is left out, it comes from `TEAM_CODE`; `null` means no gate.
  - Over HTTP:
    - Everything except `/api/health` and `/api/gate` answers a browser without the cookie with the team-code page (401, HTML) or, under `/api/`, with `401 { error, gate: true }`.
    - `POST /api/gate` takes a form with `code` and `next`. The right code answers 303 to `next`, with `oth_gate` set. A wrong code gets 401 and the page with its error. Once the limit is reached, it answers 429.

The design, in brief. There is one code for the whole team (spec §13).
- **The cookie.** It holds `HMAC-SHA256(key = code, "oth-team-gate/1")`, never the code itself. Changing `TEAM_CODE` therefore turns every existing cookie away at once. The cookie is httpOnly, `SameSite=Lax`, lasts a year, and is `Secure` in production.
- **Comparing the code.** Both sides are hashed first, then compared with `timingSafeEqual`.
- **Wrong codes.** They are counted across the whole server: 20 in any 15 minutes. Per-address counting would trust `X-Forwarded-For`, which the caller can write.
- **The page.** The server renders it itself, style inline and no script. Nothing else is served before the code: not the app, not its code, not its font.

```ts
import { z } from "zod";

/** Shorter than this, a code is a guess away even at the gate's pace (see gate/gate.ts). */
export const MIN_TEAM_CODE_LENGTH = 8;

/**
 * An optional setting where blank means unset, trimmed. Railway will save an
 * empty value, and a code pasted with a trailing space must still match the
 * code typed without one.
 */
const optionalSetting = z.preprocess(
  value => (typeof value === "string" ? value.trim() || undefined : value),
  z.string().optional(),
);

const ConfigSchema = z.object({
  NODE_ENV: z.enum(["development", "test", "production"]).default("development"),
  PORT: z.coerce.number().int().positive().default(3000),
  DATABASE_URL: z.string().optional(),
  /** Railway volume mount. Assets and published bundles live here. */
  DATA_DIR: z.string().default("./data"),
  SESSION_TTL_HOURS: z.coerce.number().int().positive().default(24 * 14),
  /** Soft locks expire quickly; the editor refreshes while you are editing. */
  LOCK_TTL_SECONDS: z.coerce.number().int().positive().default(300),
  /**
   * The one code the whole team types once per browser, before the sign-in
   * list (spec §13). Set on the Railway service by hand, never committed.
   * Unset, nothing is gated: right locally, refused in production.
   */
  TEAM_CODE: optionalSetting,
});

export type Config = z.infer<typeof ConfigSchema>;

export function loadConfig(env: NodeJS.ProcessEnv = process.env): Config {
  return ConfigSchema.parse(env);
}

/**
 * Why this server must not start serving, or null when it may. Production
 * without a team code would be the whole app, open to anyone with its
 * address, so it is refused rather than served (spec §13). Never repeats the
 * code, which would put it in Railway's logs.
 */
export function teamCodeProblem(config: Config): string | null {
  if (config.NODE_ENV !== "production") return null;
  if (!config.TEAM_CODE) {
    return "TEAM_CODE is not set, and in production the app is not served without it. " +
      "Set TEAM_CODE on the Railway service, then redeploy.";
  }
  if (config.TEAM_CODE.length < MIN_TEAM_CODE_LENGTH) {
    return `TEAM_CODE is shorter than ${MIN_TEAM_CODE_LENGTH} characters. ` +
      "Choose a longer one (a few words is best), set it again, then redeploy.";
  }
  return null;
}
```

```ts
import { createHash, createHmac, timingSafeEqual } from "node:crypto";
import { Hono } from "hono";
import { getCookie, setCookie } from "hono/cookie";
import { createMiddleware } from "hono/factory";
import type { AppEnv } from "../app";
import { gatePage } from "./page";

export const GATE_COOKIE = "oth_gate";

/** A year: typed once per browser (spec §13). Changing TEAM_CODE ends every one at once. */
const GATE_COOKIE_MAX_AGE_S = 365 * 24 * 3600;

/**
 * Wrong codes allowed across the whole server in any window. At this pace an
 * eight-letter code would take centuries to guess; a team of six mistyping
 * now and then never meets it.
 */
export const WRONG_CODE_LIMIT = { max: 20, windowMs: 15 * 60_000 };

export const WRONG_CODE = "That isn't the team code. Check it and try again.";
export const TOO_MANY = "Too many wrong codes. Wait 15 minutes, then try again.";

/** What an API call gets without the code. `gate` tells the editor this is not a signed-out session. */
export const GATE_REFUSAL = { error: "Enter the team code first: reload the page.", gate: true };

/**
 * What the cookie holds: proof of the code, never the code. It is keyed on
 * the code itself, so a new code turns every old cookie away with no list of
 * cookies to revoke.
 */
export function gateToken(code: string): string {
  return createHmac("sha256", code).update("oth-team-gate/1").digest("base64url");
}

/** Constant time whatever the lengths: both sides are hashed to 32 bytes first. */
export function codeMatches(typed: string, code: string): boolean {
  const a = createHash("sha256").update(typed.trim()).digest();
  const b = createHash("sha256").update(code).digest();
  return timingSafeEqual(a, b);
}

function holdsPass(cookie: string | undefined, token: string): boolean {
  if (!cookie || cookie.length !== token.length) return false;
  return timingSafeEqual(Buffer.from(cookie), Buffer.from(token));
}

/**
 * Where to go once the code is right: a path on this site, and nothing
 * else. Another host, `//host`, a header-splitting newline, or an API route
 * whose JSON would be a dead end all go home instead.
 */
export function safeNext(raw: string): string {
  if (!raw.startsWith("/") || raw.startsWith("//") || raw.startsWith("/\\")) return "/";
  if (/[\r\n]/.test(raw) || raw.length > 2000) return "/";
  if (raw === "/api" || raw.startsWith("/api/")) return "/";
  return raw;
}

/**
 * Wrong codes across the whole server, in a sliding window. The count is
 * global rather than per address because the forwarded-for header can be
 * written by the caller. A flood locks out new browsers for the window, but a
 * browser already through is never asked again.
 */
export class WrongCodes {
  private times: number[] = [];

  constructor(private readonly limit: { max: number; windowMs: number } = WRONG_CODE_LIMIT) {}

  blocked(now: number): boolean {
    this.times = this.times.filter(t => now - t < this.limit.windowMs);
    return this.times.length >= this.limit.max;
  }

  record(now: number): void {
    this.times.push(now);
  }
}

/**
 * The shared team code in front of the app (spec §13): `guard` goes before
 * every route, `routes` answers the form at `/api/gate`.
 */
export function teamGate(code: string, options: { secure: boolean; now?: () => number }) {
  const token = gateToken(code);
  const wrong = new WrongCodes();
  const now = options.now ?? Date.now;
  const noStore = { "cache-control": "no-store" };

  const guard = createMiddleware<AppEnv>(async (c, next) => {
    const path = c.req.path;
    // Railway's health check, and the form's own answer, come before any code.
    if (path === "/api/health" || path === "/api/gate") return next();
    if (holdsPass(getCookie(c, GATE_COOKIE), token)) return next();
    if (path.startsWith("/api/")) return c.json(GATE_REFUSAL, 401);
    const url = new URL(c.req.url);
    return c.html(gatePage({ next: safeNext(url.pathname + url.search) }), 401, noStore);
  });

  const routes = new Hono<AppEnv>();

  routes.post("/", async c => {
    const body: Record<string, unknown> = await c.req.parseBody().catch(() => ({}));
    const typed = typeof body.code === "string" ? body.code : "";
    const next = safeNext(typeof body.next === "string" ? body.next : "/");
    const at = now();
    // Refused unchecked while blocked, the right code too: otherwise a guess
    // that redirected would still say it was right.
    if (wrong.blocked(at)) return c.html(gatePage({ next, error: TOO_MANY }), 429, noStore);
    if (!codeMatches(typed, code)) {
      wrong.record(at);
      return c.html(gatePage({ next, error: WRONG_CODE }), 401, noStore);
    }
    setCookie(c, GATE_COOKIE, token, {
      httpOnly: true,
      secure: options.secure,
      sameSite: "Lax",
      path: "/",
      maxAge: GATE_COOKIE_MAX_AGE_S,
    });
    return c.redirect(next, 303);
  });

  // A reload of the refused form's address, or a bookmark of it: start again.
  routes.get("/", c => c.redirect("/", 303));

  return { guard, routes };
}
```

Create `packages/editor/src/auth/gateReload.ts`:

```ts
const KEY = "oth.gateReloadAt";

/** Long enough that a page which comes straight back gated is not reloaded again. */
const QUIET_MS = 30_000;

function sessionStore(): Pick<Storage, "getItem" | "setItem"> | null {
  try {
    return window.sessionStorage;
  } catch {
    return null;
  }
}

/**
 * Reloads so the server can show its team-code page in place of the app.
 * Only once in half a minute: a page that loads and is refused again at
 * once, like the Vite dev server in front of an API with TEAM_CODE set,
 * must not reload for ever. Says whether it reloaded.
 */
export function reloadForGate(
  reload: () => void = () => window.location.reload(),
  storage: Pick<Storage, "getItem" | "setItem"> | null = sessionStore(),
  now: number = Date.now(),
): boolean {
  const last = Number(storage?.getItem(KEY) ?? 0);
  if (now - last < QUIET_MS) return false;
  try {
    storage?.setItem(KEY, String(now));
  } catch {
    // Nowhere to remember it: reload all the same.
  }
  reload();
  return true;
}
```

```ts
import type { NodePgDatabase } from "drizzle-orm/node-postgres";
import { Pool } from "pg";
import * as schema from "./schema";

export type Database = NodePgDatabase<typeof schema>;

/**
 * The connection pool, with a listener for the errors it raises on its own.
 *
 * Postgres can drop an idle connection at any time: a Railway restart of the
 * database, a network blip. The pool reports that as an 'error' event, and an
 * EventEmitter with no 'error' listener throws, which would take the whole
 * server down over a connection nobody was using. The pool opens a new one on
 * the next query, so this only has to say it happened.
 */
export function createPool(
  url: string,
  log: (message: string, err: unknown) => void = console.error,
): Pool {
  const pool = new Pool({ connectionString: url });
  pool.on("error", err => log("postgres: an idle connection failed; the pool will open a new one", err));
  return pool;
}

export async function createPostgresDb(url: string): Promise<Database> {
  return drizzlePg(createPool(url), { schema });
}
```

- Produces:
  - `exportData(db, dataDir, outDir): Promise<{ dir: string; counts: Counts; files: number; bytes: number }>`, which throws `ExportRefused`.
  - `importData(db, dataDir, fromDir, options?: { fileUnder?: string }): Promise<{ counts: Counts; files: { copied: number; alreadyThere: number }; filed: string[]; unfiled: string[] }>`, which throws `ImportRefused`.
  - From `dataTables.ts`: `CARRIED_TABLES`, `LEFT_BEHIND`, `FILE_TABLES`, `unknownTables(db)`, `countRows(db)`, `migrationCount(db)`, `portablePath(p)`, `ExportFile`, `Counts`.
  - CLI:
    - `npm run data:export -- <empty folder>`;
    - `npm run data:import -- <folder> [--file-under <floor code>]`.

What these commands are, and are not:
- **Not a duplicate of `survey:export` / `survey:import`.** Those are the labelling pipeline: one capture's frames out to a Claude session, and proposals back in. They stay as they are. These two are a server-to-server move (spec §13).
- **The export is a folder laid out like a data directory:** `export.json` (every carried row, plus counts and the migration count), `assets/…` (every file a row names) and `published/…`.
- **Import refuses** unless every carried table is empty, which is stricter than the spec's "has rooms": nothing at all is merged. It also refuses if a file is missing or the wrong size, and it checks this before it writes a row or copies a file. Then it inserts every row in one transaction, and compares the counts with the export's inside that transaction.
- **When the files are already in place**, because they were uploaded straight into the volume, import leaves them where they are. That is how Task 8 uses it.
- **Rows are moved raw:** `select *` out, `json_populate_recordset` back in. This was checked on PGlite on 2026-09-28 against the real migrations: users, levels, rooms, audit_log and level_images came back identical.

What is carried, and what is not:
- **Carried:**
  - every table except sessions and locks: users, so that owners, authors and the audit trail resolve;
  - the audit log;
  - published versions with their bundles;
  - soft-deleted rows, so that Undo and restore keep working.
- **Left behind:** sessions and advisory locks, which belong to the server they were made on.
- **A new table stops both commands** until someone decides which list it belongs on.

**Filing the footage.** The real data's only live capture ("level 1") has no floor. Import stays a faithful copy by default, so that its counts match the export's (spec §16). `--file-under L1` files every live capture with no floor under L1 in the same transaction, with a version bump and an audit row, just as the Survey button would. Task 8 uses it, so no one has to remember to press *File under L1* before teammates arrive.

```ts
 * restore need them.

export const CARRIED_TABLES = [
  "users",
  "buildings", "levels", "rooms", "doorways", "entrances", "portals", "portal_endpoints", "nav_hints",
  "pathway_kinds", "pathways", "assets", "placements", "tenants", "level_images",

/** Tables whose rows name a file under the data folder, in `storage_path`, with its `size_bytes`. */
export const FILE_TABLES = ["assets", "level_images", "keyframes"] as const;

export type TableName = (typeof CARRIED_TABLES)[number];
export type Counts = Record<TableName, number>;

export const EXPORT_FORMAT = "oth-data-export";
export const EXPORT_VERSION = 1;

/** `export.json`: the rows as the database gave them, raw, with what to check them against. */
export type ExportFile = {
  format: typeof EXPORT_FORMAT;
  version: typeof EXPORT_VERSION;
  exportedAt: string;
  migrations: number;
  counts: Counts;
  files: number;
  tables: Record<TableName, Record<string, unknown>[]>;
};

/**
 * Tables in the schema that neither list mentions. A migration that adds one
 * stops both commands until someone decides whether it is carried, rather
 * than letting it be left behind unnoticed.
 */
export async function unknownTables(db: Database): Promise<string[]> {
  const { rows } = await db.execute<{ tablename: string }>(
    sql`select tablename from pg_tables where schemaname = 'public' order by tablename`,
  );
  const known = new Set<string>([...CARRIED_TABLES, ...LEFT_BEHIND]);
  return rows.map(r => r.tablename).filter(t => !known.has(t));
}

export async function countRows(db: Database): Promise<Counts> {
  const counts = {} as Counts;
  for (const table of CARRIED_TABLES) {
    const { rows } = await db.execute<{ n: number }>(
      sql`select count(*)::int as n from ${sql.identifier(table)}`,
    );
    counts[table] = rows[0]?.n ?? 0;
  }
  return counts;
}

/** How far the schema has come: an export fits only a database at the same point. */
export async function migrationCount(db: Database): Promise<number> {
  const { rows } = await db.execute<{ n: number }>(
    sql`select count(*)::int as n from drizzle.__drizzle_migrations`,
  );
  return rows[0]?.n ?? 0;
}

/** Forward slashes, whatever wrote it: the Windows laptop wrote `assets\ab\….jpg`. */
export function portablePath(path: string): string {
  return path.replace(/\\/g, "/");
```

```ts
  migrationCount, portablePath, unknownTables,
  type Counts, type ExportFile, type TableName,

export class ExportRefused extends Error {
  override name = "ExportRefused";
}

async function sizeOf(path: string): Promise<number | null> {
  try {
    return (await stat(path)).size;
  } catch {
    return null;
  }
}

async function emptyOrMissing(dir: string): Promise<boolean> {
  try {
    return (await readdir(dir)).length === 0;
  } catch {
    return true;
  }
}

/**
 * Writes one server's model to a folder laid out like a data folder:
 * `export.json` beside `assets/` and `published/`. That covers every carried
 * row, and every file those rows name. data:import reads it into another
 * server (spec §13).
 *
 * Run it against a copy of a PGlite data folder, never one a running server
 * holds. Every file is checked for being there, at the size its row records,
 * before anything is written.
 */
export async function exportData(
  db: Database, dataDir: string, outDir: string,
): Promise<{ dir: string; counts: Counts; files: number; bytes: number }> {
  const dir = resolve(outDir);
  if (!(await emptyOrMissing(dir))) {
    throw new ExportRefused(`${dir} already has files in it. Export into a new, empty folder.`);
  }
  const unknown = await unknownTables(db);
  if (unknown.length > 0) {
    throw new ExportRefused(
      `data:export doesn't know the table(s) ${unknown.join(", ")}. ` +
        "Add each to CARRIED_TABLES or LEFT_BEHIND in cli/dataTables.ts.",
    );
  }

  const tables = {} as Record<TableName, Record<string, unknown>[]>;
  for (const table of CARRIED_TABLES) {
    const { rows } = await db.execute(sql`select * from ${sql.identifier(table)}`);
    tables[table] = rows as Record<string, unknown>[];
  }

  // Each file once, however many rows name it, and with forward slashes in
  // the rows from here on, so the new server finds it on Linux.
  const sizes = new Map<string, number>();
  for (const table of FILE_TABLES) {
    for (const row of tables[table]) {
      const path = portablePath(String(row.storage_path));
      row.storage_path = path;
      sizes.set(path, Number(row.size_bytes));
    }
  }

  const wrong: string[] = [];
  for (const [path, size] of sizes) {
    if ((await sizeOf(assetFile(dataDir, path))) !== size) wrong.push(path);
  }
  if (wrong.length > 0) {
    throw new ExportRefused(
      `${wrong.length} file(s) the rows name are not in ${dataDir} at the size recorded, ` +
        `e.g. ${wrong.slice(0, 3).join(", ")}. Copy the whole data folder, assets included, and export again.`,
    );
  }

  await mkdir(dir, { recursive: true });
  let bytes = 0;
  for (const [path, size] of sizes) {
    const target = assetFile(dir, path);
    await mkdir(dirname(target), { recursive: true });
    await copyFile(assetFile(dataDir, path), target);
    bytes += size;
  }
  // The published bundles are files that published_versions rows point at by version.
  if ((await sizeOf(join(dataDir, "published"))) !== null) {
    await cp(join(dataDir, "published"), join(dir, "published"), { recursive: true });
  }

  const counts = Object.fromEntries(CARRIED_TABLES.map(t => [t, tables[t].length])) as Counts;
  const file: ExportFile = {
    format: EXPORT_FORMAT,
    version: EXPORT_VERSION,
    exportedAt: new Date().toISOString(),
    migrations: await migrationCount(db),
    counts,
    files: sizes.size,
    tables,
  };
  await writeFile(join(dir, "export.json"), JSON.stringify(file), "utf8");
  return { dir, counts, files: sizes.size, bytes };
}
```

- [ ] **Step 5: The import**

Create `packages/server/src/cli/dataImport.ts`:

```ts
import { copyFile, cp, mkdir, readFile, stat } from "node:fs/promises";
import { dirname, join, resolve } from "node:path";
import { and, eq, isNull, sql } from "drizzle-orm";
import { assetFile } from "../assets/storage";
import type { Database } from "../db/client";
import type { Row } from "../db/rows";
import { captures, levels } from "../db/schema";
import { recordAudit } from "../entities/repository";
import {
  CARRIED_TABLES, EXPORT_FORMAT, EXPORT_VERSION, FILE_TABLES,
  countRows, migrationCount, unknownTables,
  type Counts, type ExportFile,
} from "./dataTables";

export class ImportRefused extends Error {
  override name = "ImportRefused";
}

/** Rows per statement: well inside any parameter limit, and few round trips. */
const CHUNK = 500;

async function sizeOf(path: string): Promise<number | null> {
  try {
    return (await stat(path)).size;
  } catch {
    return null;
  }
}

/**
 * Every file the rows name, in the data folder at its recorded size. A file
 * already there is left alone, which is the case when the export was
 * uploaded straight into the volume. Anything missing refuses the import
 * before a file is copied or a row is written.
 */
async function placeFiles(file: ExportFile, from: string, dataDir: string) {
  const sizes = new Map<string, number>();
  for (const table of FILE_TABLES) {
    for (const row of file.tables[table] ?? []) sizes.set(String(row.storage_path), Number(row.size_bytes));
  }
  const toCopy: string[] = [];
  const missing: string[] = [];
  let alreadyThere = 0;
  for (const [path, size] of sizes) {
    if ((await sizeOf(assetFile(dataDir, path))) === size) alreadyThere += 1;
    else if ((await sizeOf(assetFile(from, path))) === size) toCopy.push(path);
    else missing.push(path);
  }
  if (missing.length > 0) {
    throw new ImportRefused(
      `${missing.length} file(s) are neither in ${dataDir} nor in ${from} at the size their rows record, ` +
        `e.g. ${missing.slice(0, 3).join(", ")}. Nothing was imported.`,
    );
  }
  for (const path of toCopy) {
    const target = assetFile(dataDir, path);
    await mkdir(dirname(target), { recursive: true });
    await copyFile(assetFile(from, path), target);
  }
  return { copied: toCopy.length, alreadyThere };
}

/**
 * Files every live capture that has no floor under the floor with this code,
 * as Survey's "File under" button would: a version on, and on the record.
 */
async function fileUnfiled(tx: Database, code: string): Promise<string[]> {
  const [level] = await tx.select().from(levels).where(and(eq(levels.code, code), isNull(levels.deletedAt)));
  if (!level) throw new ImportRefused(`There is no floor ${code} in this export. Nothing was imported.`);
  const waiting = await tx.select().from(captures).where(and(isNull(captures.levelId), isNull(captures.deletedAt)));
  for (const before of waiting) {
    const [after] = await tx.update(captures)
      .set({ levelId: level.id, version: before.version + 1, updatedAt: new Date(), updatedBy: null })
      .where(eq(captures.id, before.id))
      .returning();
    await recordAudit(tx, "capture", before.id, "update", null, before as Row, (after ?? null) as Row | null);
  }
  return waiting.map(c => c.filename);
}

/**
 * Reads a data:export folder into this server's empty database and data
 * folder (spec §13). It refuses rather than merges: any carried table with
 * a row in it stops it. Every row goes in one transaction, and the counts
 * are checked against the export's inside that transaction, so the result
 * is all of it or none of it (spec §16).
 */
export async function importData(
  db: Database, dataDir: string, fromDir: string, options: { fileUnder?: string } = {},
): Promise<{ counts: Counts; files: { copied: number; alreadyThere: number }; filed: string[]; unfiled: string[] }> {
  const from = resolve(fromDir);
  let file: ExportFile;
  try {
    file = JSON.parse(await readFile(join(from, "export.json"), "utf8")) as ExportFile;
  } catch {
    throw new ImportRefused(`${from} has no readable export.json. Point data:import at the folder data:export wrote.`);
  }
  if (file.format !== EXPORT_FORMAT || file.version !== EXPORT_VERSION) {
    throw new ImportRefused(`${join(from, "export.json")} isn't a data:export file this version reads.`);
  }

  const unknown = await unknownTables(db);
  if (unknown.length > 0) {
    throw new ImportRefused(
      `data:import doesn't know the table(s) ${unknown.join(", ")}. ` +
        "Add each to CARRIED_TABLES or LEFT_BEHIND in cli/dataTables.ts.",
    );
  }
  const migrations = await migrationCount(db);
  if (migrations !== file.migrations) {
    throw new ImportRefused(
      `The export was made at migration ${file.migrations}, and this database is at ${migrations}. ` +
        "Export and import with the same version of the app.",
    );
  }
  const before = await countRows(db);
  const occupied = CARRIED_TABLES.filter(t => before[t] > 0);
  if (occupied.length > 0) {
    throw new ImportRefused(
      `This database already has data (${occupied.map(t => `${t}: ${before[t]}`).join(", ")}). ` +
        "data:import only fills an empty database; it never merges.",
    );
  }
  const code = options.fileUnder;
  if (code && !(file.tables.levels ?? []).some(l => l.code === code && l.deleted_at == null)) {
    throw new ImportRefused(`There is no floor ${code} in this export. Nothing was imported.`);
  }

  const files = await placeFiles(file, from, dataDir);
  if (resolve(from) !== resolve(dataDir) && (await sizeOf(join(from, "published"))) !== null) {
    await cp(join(from, "published"), join(dataDir, "published"), { recursive: true, force: false });
  }

  const done = await db.transaction(async t => {
    const tx = t as unknown as Database;
    for (const table of CARRIED_TABLES) {
      const rows = file.tables[table] ?? [];
      for (let i = 0; i < rows.length; i += CHUNK) {
        const chunk = JSON.stringify(rows.slice(i, i + CHUNK));
        await tx.execute(
          sql`insert into ${sql.identifier(table)} select * from json_populate_recordset(null::${sql.identifier(table)}, ${chunk}::json)`,
        );
      }
    }
    const counts = await countRows(tx);
    const short = CARRIED_TABLES.filter(t => counts[t] !== file.counts[t]);
    if (short.length > 0) {
      throw new ImportRefused(
        `The counts differ from the export's for ${short.map(t => `${t} (${counts[t]} of ${file.counts[t]})`).join(", ")}. ` +
          "Nothing was imported.",
      );
    }
    const filed = code ? await fileUnfiled(tx, code) : [];
    const unfiled = (await tx.select({ filename: captures.filename }).from(captures)
      .where(and(isNull(captures.levelId), isNull(captures.deletedAt)))).map(c => c.filename);
    return { counts, filed, unfiled };
  });

  return { ...done, files };
}
```

```ts
/**
 * The smoke test (spec §14): the paths that matter, end to end, on a running
 * server. The team code, signing in, tagging a frame, accepting a proposal
 * and taking it back, placing an entrance, and Publish refusing with its
 * reasons. Run by hand with `npm run e2e`, never by `npm test`.
 *
 * It is safe on the team's live server. Everything it makes carries this
 * run's stamp and is taken away again: the place a tag makes, the tag, a
 * test area and the entrance placed in it. The accept is undone through its
 * own Undo, and it never presses a Publish that would go through. The last
 * test checks nothing is left, and afterAll clears up after a run that
 * failed partway.
 *
 *   E2E_BASE_URL  the server; default http://localhost:3055, the sandbox (never :3000)
 *   TEAM_CODE     only when the server asks for it; never printed
 *   E2E_USER      who signs in; default "Demo Author"
 *   E2E_FLOOR     which floor; default L1
 */
import { expect, test, type APIRequestContext, type Page } from "@playwright/test";

const BASE = process.env.E2E_BASE_URL ?? "http://localhost:3055";
const USER = process.env.E2E_USER ?? "Demo Author";
const FLOOR = process.env.E2E_FLOOR ?? "L1";

if (new URL(BASE).port === "3000") {
  throw new Error("Never run the smoke test against :3000: that is the live dev server and its database.");
}

/** This run's stamp, on everything it makes. */
const RUN = Date.now();
const TAG_NAME = `Smoke test ${RUN}`;
const AREA_ID = `smoke-area-${RUN}`;
const AREA_NAME = `Smoke test area ${RUN}`;
/** Far from the building, so the area overlaps nothing real and a click in it can only mean it. */
const AREA_RING = [[-500, -500], [-470, -500], [-470, -470], [-500, -470]];

type Row = { id: string; version: number; updatedBy?: string };
type Model = {
  levels: (Row & { code: string })[];
  places: (Row & { nameEn: string })[];
  sightings: (Row & { placeId: string })[];
  rooms: Row[];
  entrances: (Row & { roomId: string })[];
};

test.describe.configure({ mode: "serial" });

let page: Page;
let levelId = "";
let myId = "";

async function model(api: APIRequestContext): Promise<Model> {
  const res = await api.get("/api/model");
  if (!res.ok()) throw new Error(`GET /api/model answered ${res.status()}`);
  return (await res.json()) as Model;
}

async function remove(api: APIRequestContext, type: string, row: Row): Promise<void> {
  const res = await api.delete(`/api/entities/${type}/${row.id}`, { data: { expectedVersion: row.version } });
  if (!res.ok()) throw new Error(`deleting ${type} ${row.id} answered ${res.status()}`);
}

/** An entrance this run placed: in its area or, if a click missed, anywhere, by this user, since the run began. */
function placedByThisRun(e: Model["entrances"][number]): boolean {
  if (e.roomId === AREA_ID) return true;
  const at = Number(e.id.split("-entrance-")[1]);
  return e.updatedBy === myId && Number.isFinite(at) && at >= RUN;
}

/** Takes away everything this run made. Safe to run twice. */
async function cleanUp(api: APIRequestContext): Promise<void> {
  const m = await model(api);
  for (const place of m.places.filter(p => p.nameEn === TAG_NAME)) {
    for (const s of m.sightings.filter(s => s.placeId === place.id)) await remove(api, "sighting", s);
    await remove(api, "place", place);
  }
  for (const e of m.entrances.filter(placedByThisRun)) await remove(api, "entrance", e);
  for (const r of m.rooms.filter(r => r.id === AREA_ID)) await remove(api, "room", r);
}

test.beforeAll(async ({ browser }) => {
  // A page of its own, shared by every test: `browser.newPage` does not take
  // the config's `use`, so the address and the size are given here.
  page = await browser.newPage({ baseURL: BASE, viewport: { width: 1440, height: 900 } });
});

test.afterAll(async () => {
  if (myId) {
    await cleanUp(page.request).catch(err => console.log(`Cleaning up after a failed run: ${String(err).split("\n")[0]}`));
  }
  await page.close();
});

test("the team code, then signing in by picking a name", async () => {
  await page.goto("/");
  const code = page.getByLabel("Team code");
  const who = page.getByLabel("Who are you?");
  await expect(code.or(who)).toBeVisible();
  if (await code.isVisible()) {
    const typed = process.env.TEAM_CODE;
    if (!typed) {
      throw new Error("This server asks for the team code. Run with TEAM_CODE set: `railway run` passes it without printing it.");
    }
    await code.fill(typed);
    await page.getByRole("button", { name: "Continue" }).click();
  }
  await expect(who).toBeVisible();
  const names = (await who.locator("option").allInnerTexts()).filter(n => n !== "Pick your name");
  if (!names.includes(USER)) throw new Error(`${USER} isn't on this server's team (${names.join(", ")}). Set E2E_USER.`);
  await who.selectOption({ label: USER });
  await page.getByRole("button", { name: "Sign in" }).click();
  await expect(page.getByRole("heading", { name: "Floors" })).toBeVisible();

  myId = ((await (await page.request.get("/api/auth/me")).json()) as { user: { id: string } }).user.id;
  levelId = (await model(page.request)).levels.find(l => l.code === FLOOR)?.id ?? "";
  expect(levelId, `this server has no floor ${FLOOR}`).not.toBe("");
});

test("Survey: tag a frame, then take the tag off again", async () => {
  await page.goto(`/floors/${FLOOR}/survey`);
  const frame = page.getByText(/^Frame \d+ of \d+/).first();
  const unfiled = page.getByText(/isn't filed under a floor/).first();
  await expect(frame.or(unfiled).first()).toBeVisible({ timeout: 30_000 });
  if (!(await frame.isVisible())) {
    throw new Error(`${FLOOR} has no footage filed under it: import with --file-under ${FLOOR}, or press File under ${FLOOR} in Survey.`);
  }
  await page.getByLabel("Place name").fill(TAG_NAME);
  await page.getByRole("button", { name: "Tag", exact: true }).click();
  // The panel's × carries this name, and so does the frame's, for a boxed tag.
  const untag = page.getByRole("button", { name: `Remove tag ${TAG_NAME} from this frame` });
  await expect(untag.first()).toBeVisible({ timeout: 15_000 });
  await untag.first().click();
  // First: Radix also renders a toast's words once more, for screen readers.
  await expect(page.getByText(`Deleted the tag ${TAG_NAME}`).first()).toBeVisible();
  await expect(untag).toHaveCount(0, { timeout: 15_000 });
});

test("Review: accept a proposal, then Undo puts it back", async () => {
  await page.goto(`/floors/${FLOOR}/review`);
  const accept = page.getByRole("button", { name: /^Accept/ });
  const nothing = page.getByText(`Nothing waiting on ${FLOOR}.`);
  await expect(accept.or(nothing).first()).toBeVisible({ timeout: 30_000 });
  if (await nothing.isVisible()) throw new Error(`${FLOOR} has no proposals waiting, so there is nothing to accept.`);
  const name = (await page.getByLabel("Name", { exact: true }).inputValue()).trim();
  await accept.click();
  await expect(page.getByText(`Accepted ${name}`).first()).toBeVisible();
  await page.getByRole("button", { name: "Undo" }).click();
  await expect(page.getByText(/is back in the queue$/).first()).toBeVisible({ timeout: 15_000 });
});

test("Build: place an entrance in the Entrances & lifts step", async () => {
  const made = await page.request.post("/api/entities/room", {
    data: {
      data: {
        id: AREA_ID, levelId, kind: "area", walkable: true, heightM: 4,
        nameEn: AREA_NAME, footprint: AREA_RING,
      },
    },
  });
  expect(made.ok(), `making the test area answered ${made.status()}`).toBeTruthy();

  // The link selects the area and zooms to it, which puts its middle in the canvas's middle.
  await page.goto(`/floors/${FLOOR}/build?step=entrances&select=room:${AREA_ID}`);
  const guide = page.getByRole("region", { name: "Entrances & lifts guide" });
  await expect(guide).toBeVisible({ timeout: 30_000 });
  await expect(page.getByRole("region", { name: "Selection" }).getByLabel("Name", { exact: true })).toHaveValue(AREA_NAME);
  // The zoom lands in the render after the selection.
  await page.waitForTimeout(500);

  await guide.getByRole("button", { name: /^Entrance/ }).click();
  const surface = await page.getByTestId("plan-surface").boundingBox();
  if (!surface) throw new Error("the plan is not on screen");
  await page.mouse.click(surface.x + surface.width / 2, surface.y + surface.height / 2);

  await expect
    .poll(async () => (await model(page.request)).entrances.filter(e => e.roomId === AREA_ID).length, { timeout: 15_000 })
    .toBe(1);
});

test("Publish is refused, and says what to fix", async () => {
  await page.goto("/floors");
  const publish = page.getByRole("button", { name: /^Publish/ });
  // Only the blocked button carries ▾. One that would publish is never pressed.
  await expect(publish).toHaveText(/▾/, { timeout: 15_000 });
  await publish.click();
  await expect(page.getByText(/before publishing:$/)).toBeVisible({ timeout: 15_000 });
  await expect(page.getByRole("link", { name: /→/ }).first()).toBeVisible();
  await page.keyboard.press("Escape");
});

test("leaves nothing of itself behind", async () => {
  await cleanUp(page.request);
  const m = await model(page.request);
  expect(m.places.filter(p => p.nameEn === TAG_NAME)).toEqual([]);
  expect(m.rooms.filter(r => r.id === AREA_ID)).toEqual([]);
  expect(m.entrances.filter(placedByThisRun)).toEqual([]);
});
```
