# Plan 6A — Objects — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A label is a kind; the map has each one. Tagging a frame as an Object makes or reuses a kind such as "wastebin". Places lists the kinds, with their size, their model and their frames, and turns any place into one. Every object on the map is a placement: a turned square on the plan, and in 3D the kind's model or a box of its size. Each kind goes to Blender and comes back once.

**Architecture:**
- **Model.** `ObjectKindSchema` joins `dressing.ts`. A placement's `assetId` becomes optional, and it gains `objectKindId` and `sightingIds`. A place gains `objectKindId`, the way `pathwayKindId` marks a walkway, so sightings, Review and the survey tools work unchanged. "An asset or a kind" is a validation rule, not a zod refine.
- **Server.** Migration `0014` carries all of Plan 6's DDL, `floor_setup` included. `objectKind` joins the entity registry, so generic CRUD, the MCP tools and the audit log need no new route.
- **Renderer.** `objectBox.ts` builds the box, which 6B reuses. `objectExport.ts` feeds `buildDetailGlb` a block of the kind's size in place of a traced outline.
- **Editor.**
  - The tag bar gets a third choice.
  - `places/objects.ts` holds the Objects section's pure rules, and `ObjectsSection.tsx` draws them.
  - `PlacementMarker` turns the plan's placement squares.

**Tech Stack:** TypeScript (strict, `noUncheckedIndexedAccess`), zod 3, Drizzle 0.36.4 with drizzle-kit 0.28.1 (PGlite in tests, Postgres on Railway), Hono, React 18, zustand, Tailwind 3, react-three-fiber 8, `@react-three/drei` (`Html`, `useGLTF`), three 0.169, `@gltf-transform/core` 4, Vitest 1.6 (node for model, server and renderer; jsdom for the editor).

## Review Focus

1. **Tagging a name that is already a plain place as an Object.** The live data has "wastebin" as a place with no kind. The tag must turn that place into the kind's place, not make a second "wastebin". Tagging "wastebin" on L2 must find the same kind, although its sightings put the place on L1. Pinned in Task 5 (`tagWrites`, `linkablePlaces`, `TagBar`).
2. **A retried tag after half of it landed.** The kind is made, then the place fails. Retry must reuse that kind by name. Two "wastebin" kinds would each need a model. Pinned in Task 5 (`kindNamed`, and the SurveyWorkspace retry test).
3. **A kind's model that will not load**, such as a deleted file or a broken upload. Every object of the kind must show its box, not vanish, and the next preview must try the file again. Pinned in Task 1 (`forgetPlacementModels` forgets a kind's model) and Task 3 (`PlacementBoundary`'s `fallback`).
4. **A placement with neither a model nor a kind.** It can come from `/api/entities`, from Claude's `create`, or from an `update` that clears one. The answer must be a 422 or a refusal naming the rule, not the database's check as a 500. Publish must refuse one that got in. Pinned in Task 2 (the repository guard, the routes and MCP tests) and Task 1 (the rule).
5. **A size typed wrong.** Blank, 0, negative, `1,2`, or 60 meaning centimetres must be refused on the form, with the reason, before anything is sent. Pinned in Task 6 (`parseSize`) and Task 7 (the Objects section's forms).

## Decisions this plan makes where the spec is silent

- **Which way is front.** At rotation 0 an object faces south, which is glTF's front, +Z. `rotationDeg` turns it anticlockwise seen from above, as `PlacementMesh` already turns a model. The rule is written once, as `objectFront` and `facingRotation` in `@oth/model`, so the plan marker, the export and 6C's spots all agree.
- **An object's place has no floor, and is linkable from every floor.** A kind is the same thing on L1 and L2. `placeLevels` still infers a floor from sightings, so `linkablePlaces` lets object places through wherever they were filmed. A new object place from the tag bar is written with no `levelId`.
- **A new kind from the tag bar starts at 0.5 × 0.5 × 1 m** (`OBJECT_SIZE_GUESS`). The spec asks for a size only on "This is an object". The tag bar says the size is a guess, and the Objects section changes it.
- **Kinds are matched by name.** Matching ignores case and spacing, as place names already are (`normalName`).
  - Tagging "Wastebin" when the kind "wastebin" exists reuses it.
  - So does "This is an object" on a place named like an existing kind. The place joins the kind at its size, and the form says so instead of asking.
- **"This is an object" has one form, in the Objects section.**
  - It lists every live place that is not an object, not a walkway, and not bound to a live room. That includes proposals (Claude's 8) and places no floor claims, which the checklist never lists.
  - A checklist row with no room has a **This is an object** button that picks its place in that form.
- **Objects leave the checklist and Bind places.** They are placed as markers, never bound. `placeRows`, `floorUnits`, the `place.unbound` warning and the server's `bindPlace` all skip a place with `objectKindId`, as they already skip walkways.
- **The Places tab now writes**, so it takes the shell's saver, which validates. A kind's model is checked at publish (`objectKind.asset.missing`).
- **Sizes on the forms are metres, above 0 and at most 10 m.** Anything larger is almost always centimetres typed as metres. Decimals take a dot. The schema itself only asks for positive and finite, as interfaces.md fixes it.
- **The export.**
  - The box sits square to the file's axes at the origin.
  - The surroundings turn by the object's rotation, so what the object faces is in front of it, at +Z.
  - Its surroundings come from one of its objects: this floor's first by id, else any floor's. With none on the map, the file holds the box alone.
  - The file is named from the English name, lower-case and hyphenated ("water cooler" becomes `oth-object-water-cooler.glb`), or from the id when that leaves nothing.
  - The box is built as `buildDetailGlb` builds a traced detail: a floor and four sides, open at the top.
- **The published bundle carries `objectKinds` in `placements.json`, and drops each placement's `sightingIds`.** Sighting ids point into the survey layer, which the bundle never ships.
- **Validation codes**, all errors, like `placement.asset.missing`:
  - `placement.assetOrKind.missing`;
  - `placement.objectKind.missing`;
  - `objectKind.asset.missing`.
- **Out of scope:**
  - placing an object on the map by hand, since spec §5 names no such action;
  - deleting a kind in the app.

  Objects reach the map through Claude (6C) or the MCP `create` tool.

```ts
import { live, type Vec2 } from "./primitives";
import type { ObjectKind, Placement } from "./schema/dressing";

/**
 * The size a kind starts at when nobody has measured it: about a wastebin's,
 * in metres. Survey's Object tag makes kinds at this size, and it can be
 * changed in Places.
 */
export const OBJECT_SIZE_GUESS: Readonly<ObjectKind["size"]> = { w: 0.5, d: 0.5, h: 1 };

/**
 * The model a placement shows (spec §5.3): its own, else its kind's. None
 * while neither has one, and an object is then drawn as a box of its kind's
 * size. A deleted kind lends nothing.
 */
export function placementModelAsset(
  model: { readonly objectKinds: readonly ObjectKind[] },
  placement: Pick<Placement, "assetId" | "objectKindId">,
): string | undefined {
  if (placement.assetId) return placement.assetId;
  if (!placement.objectKindId) return undefined;
  return live(model.objectKinds).find(k => k.id === placement.objectKindId)?.assetId;
}

/**
 * Which way an object faces on the plan, as a unit vector (x east, y north).
 *
 * The one convention every part shares:
 * - at rotation 0 an object faces south, which is glTF's front: +Z, since
 *   north is -Z;
 * - rotationDeg turns it anticlockwise seen from above, as the 3D preview
 *   turns a placed model about its vertical axis.
 *
 * So a modeller builds the front facing +Z, the plan marker draws its tick
 * this way, and Claude's spots turn objects to face into the walkway with
 * `facingRotation`.
 */
export function objectFront(rotationDeg: number): Vec2 {
  const r = (rotationDeg * Math.PI) / 180;
  return [Math.sin(r), -Math.cos(r)];
}

/** The rotation, in [0, 360), that turns an object's front to face `direction`. A direction of no length faces south. */
export function facingRotation(direction: Vec2): number {
  const [x, y] = direction;
  if (x === 0 && y === 0) return 0;
  const deg = (Math.atan2(x, -y) * 180) / Math.PI;
  return ((deg % 360) + 360) % 360;
}
```

```ts
import { live, placementModelAsset, type ObjectKind, type Placement } from "@oth/model";
import * as THREE from "three";

export type ObjectSize = ObjectKind["size"];

/** stone-400: a kind with no model yet reads as a stand-in beside the category tints. */
export const OBJECT_BOX_COLOUR = "#a8a29e";

/**
 * A kind's box, w across, h up and d deep, standing on the origin at its base
 * centre, the way a modeller's model stands. The preview draws it for a kind
 * with no model yet, and the floor export (Plan 6B) writes the same one.
 */
export function objectBoxGeometry(size: ObjectSize): THREE.BufferGeometry {
  const geometry = new THREE.BoxGeometry(size.w, size.h, size.d);
  geometry.translate(0, size.h / 2, 0);
  return geometry;
}

export type PlacementLook =
  /** A model to load; an object's box to show while it loads, and in place of one that will not. */
  | { as: "model"; assetId: string; box: { size: ObjectSize; name: string } | null }
  | { as: "box"; size: ObjectSize; name: string }
  | { as: "nothing" };

/**
 * What the preview draws for a placement (spec §5.3): its model, which is its
 * own or its kind's, or while it has none, its kind's box. A placement with
 * neither is a validation error and draws nothing.
 */
export function placementLook(placement: Placement, kinds: readonly ObjectKind[]): PlacementLook {
  const kind = placement.objectKindId ? live(kinds).find(k => k.id === placement.objectKindId) : undefined;
  const box = kind ? { size: kind.size, name: kind.nameEn } : null;
  const assetId = placementModelAsset({ objectKinds: kinds }, placement);
  if (assetId) return { as: "model", assetId, box };
  return box ? { as: "box", ...box } : { as: "nothing" };
}
```

```tsx
/**
 * One placed model that will not load — its file gone, a broken upload —
 * draws its fallback, and the rest of the level draws as usual. An object's
 * fallback is its kind's box, so it never just vanishes; a placed model has
 * none. Suspense does not catch a failed load, only a pending one. The
 * failure is forgotten as it is caught, so the next time the scene mounts the
 * file is tried again.
 */
export class PlacementBoundary extends Component<
  { url: string; fallback?: ReactNode; children: ReactNode },
  { failed: boolean }
> {
  override state = { failed: false };

  static getDerivedStateFromError() {
    return { failed: true };
  }

  override componentDidCatch() {
    useGLTF.clear(this.props.url);
  }

  override render() {
    return this.state.failed ? this.props.fallback ?? null : this.props.children;
  }
```

```ts
import { RoomSchema, type Level, type ObjectKind, type Placement, type Room, type Vec2 } from "@oth/model";
import { buildDetailGlb, detailContextRooms } from "./contextExport";

/** Spec §5.5: the surroundings within 5 m of one of its objects. */
export const OBJECT_CONTEXT_MARGIN_M = 5;

export const OBJECT_ORIGIN_NOTE =
  "Origin is the object's base centre. Units are metres. Y is up, and the object's front faces +Z. " +
  "Model inside the box: every object of this kind shows the model, turned and placed as on the map.";

/** `oth-object-water-cooler.glb`: the English name, lower-case and hyphenated, or the id when that leaves nothing. */
export function objectKindExportName(kind: Pick<ObjectKind, "id" | "nameEn">): string {
  const slug = kind.nameEn.trim().toLowerCase().replace(/[^a-z0-9]+/g, "-").replace(/^-+|-+$/g, "");
  return `oth-object-${slug || kind.id}.glb`;
}

/** A point turned about another, anticlockwise seen from above. */
function turn(p: Vec2, about: Vec2, deg: number): [number, number] {
  const r = (deg * Math.PI) / 180;
  const dx = p[0] - about[0];
  const dy = p[1] - about[1];
  return [about[0] + dx * Math.cos(r) - dy * Math.sin(r), about[1] + dx * Math.sin(r) + dy * Math.cos(r)];
}

function turnRoom(room: Room, about: Vec2, deg: number): Room {
  if (deg % 360 === 0) return room;
  return {
    ...room,
    footprint: room.footprint.map(p => turn(p, about, deg)),
    holes: room.holes.map(hole => hole.map(p => turn(p, about, deg))),
  };
}

/** The kind's box as a traced detail is: a rectangle w across and d deep about `at`, as tall as the kind. */
function kindBlock(kind: ObjectKind, at: Vec2, levelId: string): Room {
  const w = kind.size.w / 2;
  const d = kind.size.d / 2;
  return RoomSchema.parse({
    id: kind.id, levelId, kind: "detail", nameEn: kind.nameEn, heightM: kind.size.h,
    footprint: [[at[0] - w, at[1] - d], [at[0] + w, at[1] - d], [at[0] + w, at[1] + d], [at[0] - w, at[1] + d]],
  });
}

/**
 * Export for modelling (spec §5.5): the kind's box, and the surroundings of
 * one of its objects as locked reference, centred on that object's base.
 *
 * It is `buildDetailGlb` with a box in place of a traced outline. The box
 * stays square to the axes. The surroundings turn by the object's rotation,
 * so what the object faces is in front of it at +Z, which is where the model's
 * front goes. The model then comes back into every object of the kind, turned
 * as each one is. With none on the map, the box comes alone.
 *
 * `rooms` are the map's live rooms; only `level`'s are used.
 */
export async function buildObjectKindGlb(
  kind: ObjectKind, at: Placement | null, rooms: readonly Room[], level: Level,
): Promise<Uint8Array> {
  const centre: Vec2 = at ? [at.position[0], at.position[1]] : [0, 0];
  const block = kindBlock(kind, centre, level.id);
  const context = at
    ? detailContextRooms(block, rooms.filter(r => r.levelId === level.id), OBJECT_CONTEXT_MARGIN_M)
      .map(r => turnRoom(r, centre, -at.rotationDeg))
    : [];
  return (await buildDetailGlb(block, context, level, OBJECT_ORIGIN_NOTE)).bytes;
}
```

```ts
/** The kind a name means, as place names are matched: case, inner spacing and the ends ignored. */
export function kindNamed(kinds: readonly ObjectKind[], name: string): ObjectKind | undefined {
  const wanted = normalName(name);
  return wanted === "" ? undefined : kinds.find(k => normalName(k.nameEn) === wanted);
}

/** "0.5 × 0.5 × 1 m": width, depth and height, to the centimetre. */
export function sizeText(size: ObjectKind["size"]): string {
  const m = (v: number) => String(Math.round(v * 100) / 100);
  return `${m(size.w)} × ${m(size.d)} × ${m(size.h)} m`;
}

/**
 * What tagging a frame writes: a new place when the name is new — filed under
 * the floor being surveyed, so it is on that floor from the start — and the
 * sighting that ties it to the frame.
 *
 * An object also makes or reuses its kind (spec §5.1). A kind is the same on
 * every floor, so its place is filed under none. A place already surveyed
 * that is tagged as an object becomes the kind's place, rather than a second
 * place of the same name. A kind of the same name is reused, so a retry after
 * the kind landed and its place did not makes no second kind.
 */
export function tagWrites(
  tag: Tag, frameId: string, levelId: string, id: (prefix: string) => string = newId, known: Known = NOTHING_KNOWN,
): TagWrites {
  const placeId = tag.placeId ?? id("pl");
  const existing = tag.placeId ? known.places.find(p => p.id === tag.placeId) : undefined;
  let objectKind: Record<string, unknown> | null = null;
  let kindId: string | undefined;
  if (tag.object) {
    kindId = existing?.objectKindId ?? kindNamed(known.kinds, tag.nameEn)?.id;
    if (!kindId) {
      kindId = id("ok");
      objectKind = { id: kindId, nameEn: tag.nameEn, size: { ...OBJECT_SIZE_GUESS } };
    }
  }
  return {
    objectKind,
    place: tag.placeId
      ? null
      : {
          id: placeId,
          nameEn: tag.nameEn,
          category: tag.category,
          ...(kindId ? { objectKindId: kindId } : { levelId }),
          ...(tag.pathwayKindId ? { pathwayKindId: tag.pathwayKindId } : {}),
        },
    makeObject: tag.placeId && kindId && !existing?.objectKindId ? { placeId, objectKindId: kindId } : null,
    sighting: { id: id("sg"), placeId, keyframeId: frameId, ...(tag.box ? { box: tag.box } : {}) },
  };
}
```

```ts
/**
 * The places a tag on one floor may link to: that floor's, and those with no
 * floor yet. Another floor's "Toilets" is a different place, and linking to it
```

```ts
import { live, type MapModel, type ObjectKind, type Place, type Placement } from "@oth/model";
import { kindNamed, newId } from "../survey/tagging";
import { bestEvidence, type Evidence } from "./evidence";

export type ObjectSize = ObjectKind["size"];

/** A size as typed into the forms: metres, as text. */
export type SizeText = { w: string; d: string; h: string };

/** Any side longer than this was typed in centimetres: 60 for 0.6. */
export const MAX_OBJECT_SIDE_M = 10;

/** One kind of object in the Places tab's Objects section (spec §5.2). */
export type ObjectRow = {
  kind: ObjectKind;
  /** The places that stand for it in the survey: usually one. */
  places: Place[];
  /** "Model" once its kind has a model on the server; until then every one is drawn as a box. */
  look: "Box" | "Model";
  /** Its live objects per floor, lowest floor first. Floors with none are left out. */
  onMap: { code: string; count: number }[];
  /** How many frames show it, one per frame, across its places. */
  frames: number;
  /** Its best frame, for the thumbnail. */
  best: Evidence | null;
};

export function objectRows(model: MapModel): ObjectRow[] {
  const places = live(model.places);
  const assets = new Set(live(model.assets).map(a => a.id));
  const levels = [...live(model.levels)].sort((a, b) => a.ordinal - b.ordinal);
  const placements = live(model.placements);
  return [...live(model.objectKinds)]
    .sort((a, b) => a.nameEn.localeCompare(b.nameEn) || a.id.localeCompare(b.id))
    .map<ObjectRow>(kind => {
      const own = places.filter(p => p.objectKindId === kind.id);
      const evidence = own.flatMap(p => bestEvidence(model, p.id));
      const mine = placements.filter(p => p.objectKindId === kind.id);
      return {
        kind,
        places: own,
        // A model the server no longer has is drawn as the box, so it reads as one.
        look: kind.assetId && assets.has(kind.assetId) ? "Model" : "Box",
        onMap: levels
          .map(l => ({ code: l.code, count: mine.filter(p => p.levelId === l.id).length }))
          .filter(floor => floor.count > 0),
        frames: evidence.length,
        best: evidence[0] ?? null,
      };
    });
}

export function onMapText(row: ObjectRow): string {
  if (row.onMap.length === 0) return "Not on the map yet";
  return `On the map: ${row.onMap.map(f => `${f.code} ${f.count}`).join(" · ")}`;
}

export function framesText(frames: number): string {
  return frames === 0 ? "No frames" : `${frames} frame${frames === 1 ? "" : "s"}`;
}

/**
 * The places "This is an object" may turn into one (spec §5.1): any live
 * place that is not one already, not a walkway, and not bound to a room on
 * the map. Proposals are in, since Claude's 8 are proposals. So are places no
 * floor claims, which no floor's checklist lists.
 */
export function objectCandidates(model: MapModel): Place[] {
  const rooms = new Set(live(model.rooms).map(r => r.id));
  return live(model.places)
    .filter(p => !p.objectKindId && !p.pathwayKindId && !(p.roomId && rooms.has(p.roomId)))
    .sort((a, b) => a.nameEn.localeCompare(b.nameEn) || a.id.localeCompare(b.id));
}

/** Metres, with a dot for decimals. parseFloat would read "1,2" as 1, which is worse than refusing it. */
const METRES = /^\d*\.?\d+$/;

/** A size from the form, or why not. Checked before anything is sent. */
export function parseSize(text: SizeText): { ok: true; size: ObjectSize } | { ok: false; reason: string } {
  const size: ObjectSize = { w: 0, d: 0, h: 0 };
  for (const side of ["w", "d", "h"] as const) {
    const typed = text[side].trim();
    const value = METRES.test(typed) ? Number(typed) : Number.NaN;
    if (!(value > 0)) return { ok: false, reason: "Give each side in metres, above 0, like 0.6." };
    if (value > MAX_OBJECT_SIDE_M) {
      return { ok: false, reason: `${typed} m is more than ${MAX_OBJECT_SIDE_M} m. Sizes are in metres: 60 cm is 0.6.` };
    }
    size[side] = value;
  }
  return { ok: true, size };
}

export function sizeFields(size: ObjectSize): SizeText {
  return { w: String(size.w), d: String(size.d), h: String(size.h) };
}

export type MakeObject = {
  /** A new kind to make first, or null when one of this name exists and the place joins it. */
  objectKind: Record<string, unknown> | null;
  /** The kind the place joins: `{ objectKindId }` is its update. */
  objectKindId: string;
};

/**
 * "This is an object" (spec §5.1): the kind the place becomes, named after it
 * and at the size asked. A kind of the same name is joined at its own size
 * rather than doubled, the rule Survey's Object tag follows.
 */
export function makeObjectWrites(
  place: Place, size: ObjectSize, kinds: readonly ObjectKind[], id: (prefix: string) => string = newId,
): MakeObject {
  const same = kindNamed(live(kinds), place.nameEn);
  if (same) return { objectKind: null, objectKindId: same.id };
  const objectKindId = id("ok");
  return { objectKind: { id: objectKindId, nameEn: place.nameEn, nameZh: place.nameZh, size }, objectKindId };
}

/**
 * The object whose surroundings go to Blender with its kind (spec §5.5):
 * this floor's first by id, else any floor's, so the choice never changes
 * between clicks.
 */
export function referenceObject(model: MapModel, kindId: string, levelId: string): Placement | null {
  const mine = live(model.placements)
    .filter(p => p.objectKindId === kindId)
    .sort((a, b) => a.id.localeCompare(b.id));
  return mine.find(p => p.levelId === levelId) ?? mine[0] ?? null;
}
```

```tsx
import { OBJECT_SIZE_GUESS, live, type Level, type MapModel } from "@oth/model";
import { buildObjectKindGlb, objectKindExportName } from "@oth/renderer";
import { useEffect, useMemo, useRef, useState, type FormEvent } from "react";
import type { Api } from "../api/client";
import { followLink } from "../route";
import type { Saver } from "../state/save";
import { kindNamed, sizeText } from "../survey/tagging";
import { Button } from "../ui/Button";
import { reportFailure } from "../ui/failure";
import { toast } from "../ui/toast";
import { BoxedFrame } from "./BoxedFrame";
import { frameSrc, surveyLink } from "./evidence";
import {
  framesText, makeObjectWrites, objectCandidates, objectRows, onMapText, parseSize, referenceObject, sizeFields,
  type ObjectRow, type SizeText,
} from "./objects";

/** A row's thumbnail: `w-28`, as in the places checklist. */
const THUMB_CSS_PX = 112;

/** Where a new kind's size starts: the guess Survey's Object tag makes kinds at. */
const GUESS: SizeText = sizeFields(OBJECT_SIZE_GUESS);

function download(bytes: Uint8Array, filename: string): void {
  // Copied into a definite ArrayBuffer: a Uint8Array may be backed by a
  // SharedArrayBuffer as far as the types are concerned, which Blob rejects.
  const buf = new ArrayBuffer(bytes.byteLength);
  new Uint8Array(buf).set(bytes);
  const url = URL.createObjectURL(new Blob([buf], { type: "model/gltf-binary" }));
  const a = document.createElement("a");
  a.href = url;
  a.download = filename;
  a.click();
  URL.revokeObjectURL(url);
}

function SizeFields({ value, onChange }: { value: SizeText; onChange: (next: SizeText) => void }) {
  const field = (side: keyof SizeText, label: string) => (
    <label className="text-xs text-stone-600">
      {label}
      <input
        aria-label={`${label} in metres`}
        inputMode="decimal"
        className="mt-1 block h-8 w-16 rounded border border-stone-300 px-2 text-sm text-stone-900"
        value={value[side]}
        onChange={event => onChange({ ...value, [side]: event.target.value })}
      />
    </label>
  );
  return (
    <div className="flex items-end gap-2">
      {field("w", "Width")}
      {field("d", "Depth")}
      {field("h", "Height")}
      <span className="pb-2 text-xs text-stone-600">m</span>
    </div>
  );
}

/**
 * The Places tab's Objects section (spec §5.2): each kind with its size,

export function ObjectsSection({ api, saver, model, level, placeId, onPlaceId }: {
  api: Api;
  saver: Saver;
  model: MapModel;
  level: Level;
  /** The place the form is turning into an object, picked there or from a checklist row. */
  placeId: string | null;

function ObjectRowItem({ api, saver, model, level, row }: {
  api: Api; saver: Saver; model: MapModel; level: Level; row: ObjectRow;
}) {
  const { kind } = row;
  const [editing, setEditing] = useState<SizeText | null>(null);
  const [problem, setProblem] = useState<string | null>(null);
  const [busy, setBusy] = useState(false);
  const photo = row.best ? surveyLink(model, row.best.frame) : null;
  const frames = framesText(row.frames);

  async function saveSize(event: FormEvent) {
    event.preventDefault();
    if (!editing) return;
    const parsed = parseSize(editing);
    if (!parsed.ok) {
      setProblem(parsed.reason);
      return;
    }
    setProblem(null);
    setBusy(true);
    const saved = await saver.update("objectKind", kind.id, kind.version, { size: parsed.size });
    setBusy(false);
    if (saved) setEditing(null);
  }

  async function exportForModelling() {
    setBusy(true);
    try {
      // One of its objects lends the file its surroundings: this floor's, else any.
      const at = referenceObject(model, kind.id, level.id);
      const on = (at && live(model.levels).find(l => l.id === at.levelId)) || level;
      download(await buildObjectKindGlb(kind, at, live(model.rooms), on), objectKindExportName(kind));
    } catch (err) {
      toast({ tone: "error", message: `Couldn't make ${kind.nameEn}'s file: ${err instanceof Error ? err.message : String(err)}.` });
    } finally {
      setBusy(false);
    }
  }

  async function uploadModel(file: File) {
    setBusy(true);
    try {
      // The asset pipeline's own checks and limits (5 MB, 150k triangles) apply.
      const asset = await api.uploadAsset(file);
      await saver.update("objectKind", kind.id, kind.version, { assetId: asset.id });
    } catch (err) {
      reportFailure(err, { doing: `upload ${file.name}` });
    } finally {
      setBusy(false);
    }
  }

  return (
    <li data-testid={`object-row-${kind.id}`} className="space-y-2 p-2">
      <div className="flex items-center gap-3">
        {row.best ? (
          <BoxedFrame
            className="w-28 shrink-0"
            src={frameSrc(api, row.best, THUMB_CSS_PX)}
            frame={row.best.frame}
            box={row.best.sighting.box}
            tone={row.best.sighting.status}
            alt=""
          />
        ) : (
          <span className="flex h-16 w-28 shrink-0 items-center justify-center rounded bg-stone-100 text-xs text-stone-600">No photo</span>
        )}
        <div className="min-w-0 flex-1">
          <p className="truncate text-sm font-medium text-stone-900">{kind.nameEn}</p>
          <p className="text-xs text-stone-600">{sizeText(kind.size)} · {row.look}</p>
          <p className="text-xs text-stone-600">{onMapText(row)}</p>
          <p className="text-xs text-stone-600">
            {photo ? <a href={photo} onClick={followLink(photo)} className="underline">{frames}</a> : frames}
          </p>
        </div>
        <div className="flex shrink-0 flex-col items-end gap-1">
          <Button
            size="sm"
            aria-label={`Change the size of ${kind.nameEn}`}
            onClick={() => {
              setProblem(null);
              setEditing(sizeFields(kind.size));
            }}
          >
            Change size
          </Button>
          <Button
            size="sm"
            disabled={busy}
            aria-label={`Export ${kind.nameEn} for modelling`}
            title={row.onMap.length > 0
              ? "The box, with the rooms around one of these on the map."
              : "None is on the map yet, so the file has the box alone."}
            onClick={() => void exportForModelling()}
          >
            Export for modelling
          </Button>
          <label className="inline-flex h-7 cursor-pointer items-center rounded border border-stone-300 bg-white px-2.5 text-xs font-medium text-stone-900 hover:bg-stone-100">
            {row.look === "Model" ? "Replace model" : "Upload model"}
            <input
              type="file"
              accept=".glb,model/gltf-binary"
              aria-label={`Upload a model for ${kind.nameEn}`}
              className="sr-only"
              disabled={busy}
              onChange={event => {
                const file = event.target.files?.[0];
                // Cleared, so choosing the same file again after a fix still sends it.
                event.target.value = "";
                if (file) void uploadModel(file);
              }}
            />
          </label>
        </div>
      </div>
      {editing && (
        <form aria-label={`Size of ${kind.nameEn}`} className="flex flex-wrap items-end gap-2" onSubmit={e => void saveSize(e)}>
          <SizeFields value={editing} onChange={setEditing} />
          <Button type="submit" size="sm" variant="primary" disabled={busy}>Save size</Button>
          <Button size="sm" variant="ghost" onClick={() => setEditing(null)}>Cancel</Button>
          {problem && <p role="alert" className="w-full text-xs text-danger">{problem}</p>}
        </form>
      )}
    </li>
  );
}

function MakeObjectForm({ model, saver, placeId, onPlaceId }: {
  model: MapModel; saver: Saver; placeId: string | null; onPlaceId: (placeId: string | null) => void;
}) {
  const candidates = useMemo(() => objectCandidates(model), [model]);
  const place = candidates.find(p => p.id === placeId) ?? null;
  const joins = place ? kindNamed(live(model.objectKinds), place.nameEn) : undefined;
  const [size, setSize] = useState<SizeText>(GUESS);
  const [problem, setProblem] = useState<string | null>(null);
  const [busy, setBusy] = useState(false);
  const form = useRef<HTMLFormElement>(null);

  // Picked from a checklist row, the form comes into view with its place in it.
  useEffect(() => {
    if (placeId) form.current?.scrollIntoView?.({ block: "nearest" });
  }, [placeId]);

  async function submit(event: FormEvent) {
    event.preventDefault();
    if (!place) return;
    const parsed = parseSize(size);
    if (!joins && !parsed.ok) {
      setProblem(parsed.reason);
      return;
    }
    setProblem(null);
    setBusy(true);
    const writes = makeObjectWrites(place, parsed.ok ? parsed.size : OBJECT_SIZE_GUESS, model.objectKinds);
    // The kind first: a place naming a kind not yet made would be an object of nothing.
    const kindReady = writes.objectKind ? await saver.create("objectKind", writes.objectKind) : true;
    const done = kindReady && (await saver.update("place", place.id, place.version, { objectKindId: writes.objectKindId }));
    setBusy(false);
    if (!done) return;
    toast({ message: `${place.nameEn} is an object now.` });
    onPlaceId(null);
    setSize(GUESS);
  }

  return (
    <form
      ref={form}
      aria-label="Turn a place into an object"
      className="space-y-2 rounded border border-stone-200 bg-white p-3"
      onSubmit={e => void submit(e)}
    >
      <p className="text-sm font-medium text-stone-900">Is one of the places an object?</p>
      <label className="block text-xs text-stone-600">
        Which place?
        <select
          aria-label="Which place?"
          className="mt-1 block h-9 w-full max-w-sm rounded border border-stone-300 px-2 text-sm text-stone-900"
          value={place?.id ?? ""}
          onChange={event => {
            setProblem(null);
            onPlaceId(event.target.value || null);
          }}
        >
          <option value="">Choose a place…</option>
          {candidates.map(p => (
            <option key={p.id} value={p.id}>{p.nameEn}{p.status === "proposed" ? " (proposed)" : ""}</option>
          ))}
        </select>
      </label>
      {place && (joins ? (
        <p className="text-sm text-stone-700">{place.nameEn} joins the kind {joins.nameEn}, at its size, {sizeText(joins.size)}.</p>
      ) : (
        <SizeFields value={size} onChange={setSize} />
      ))}
      {problem && <p role="alert" className="text-xs text-danger">{problem}</p>}
      <Button type="submit" variant="primary" disabled={!place || busy}>This is an object</Button>
    </form>
  );
}
```

```tsx
import { objectFront } from "@oth/model";
import type { MouseEvent } from "react";
import { SELECTED_FILL, SELECTED_STROKE } from "./colours";

/** Half a marker's side, in screen pixels: a point marker's size, whatever the zoom. */
const HALF_PX = 6;
/** How far the front tick reaches from the middle: just past the square's edge. */
const TICK_PX = HALF_PX + 4;

/** A placed model: violet, as placements have always been on the plan. */
export const MODEL_FILL = "#8b5cf6";
/** An object: stone-600, the neutral of its box in 3D. */
export const OBJECT_FILL = "#57534e";

/**
 * A placement on the plan (spec §5.3): a small square at its position, turned
 * to its rotation, with a tick on the side it faces. Pressing it selects it,
 * which opens the Placement inspector, and starts a drag. Colour is not the
 * only difference: its name is on hover.
 */
export function PlacementMarker({
  testId, at, rotationDeg, object, selected, title, movable, pointerEvents, onMouseDown,
}: {
  testId: string;
  at: [number, number];
  rotationDeg: number;
  object: boolean;
  selected: boolean;
  title: string;
  movable: boolean;
  pointerEvents?: "none";
  onMouseDown: (event: MouseEvent) => void;
}) {
  const [x, y] = at;
  const [fx, fy] = objectFront(rotationDeg);
  return (
    <g data-testid={testId} pointerEvents={pointerEvents} style={{ cursor: movable ? "move" : "default" }} onMouseDown={onMouseDown}>
      <title>{title}</title>
      <rect
        x={x - HALF_PX}
        y={y - HALF_PX}
        width={HALF_PX * 2}
        height={HALF_PX * 2}
        // SVG turns clockwise on screen; the plan turns anticlockwise seen from above.
        transform={`rotate(${-rotationDeg} ${x} ${y})`}
        fill={selected ? SELECTED_FILL : object ? OBJECT_FILL : MODEL_FILL}
        stroke={selected ? SELECTED_STROKE : "#ffffff"}
        strokeWidth={1.5}
      />
      {/* Which way it faces. Screen y runs south, so the plan's y is negated. */}
      <line
        data-testid={`${testId}-front`}
        x1={x}
        y1={y}
        x2={x + fx * TICK_PX}
        y2={y - fy * TICK_PX}
        stroke={selected ? SELECTED_STROKE : "#1c1917"}
        strokeWidth={2}
        strokeLinecap="round"
        pointerEvents="none"
      />
    </g>
  );
}
```
