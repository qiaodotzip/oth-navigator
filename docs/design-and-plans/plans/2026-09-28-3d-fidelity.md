# 3D fidelity (Plan 5D) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the 3D preview a faithful, readable model of the floor: one wall where two rooms meet, doorways where people go in, voids with balustrades, lifts as shafts, escalators and stairs as flights, and columns found in the drawing.

**Architecture:** All the new geometry is pure functions over plain polygons in new renderer files (`wallPlan.ts`, `openings.ts`, `voids.ts`, `portals.ts`), tested without three.js. `structure.ts` composes them for one level. A new `StructuredLevel` wraps the existing `LevelGroup` and draws the result, so the second builder's `RoomMesh`, `LevelGroup` and `MapScene` get only small hook-ins. The data change is two columns on portal stops (`footprint`, `flipped`). The PDF finders for columns and flight outlines come last and plug into Part B's extractor.

**Tech Stack:** TypeScript, three.js with react-three-fiber (renderer), React 18 with zustand (editor), zod (`@oth/model`), Drizzle with PGlite (server), Vitest 1.6, and pdf.js (Task 8 only, pinned by Part B).

**Spec:** `docs/design-and-plans/specs/2026-09-28-map-fidelity-and-agent-access-design.md` §7 (Part D) and §8 (delivery), commit 12710ef.

## Global Constraints

- **Walls.** Spec §7: "Neighbouring rooms' edges that are parallel and within 0.4 m of each other become one wall. It is built midway between them and is as thick as the gap, which is the drawing's wall." Parallel means within 5°. When the edges coincide there is no gap, so the wall takes the old shell's 0.15 m.
- **Doors.** Spec §7: "A wall gets an opening wherever a live pathway crosses it, as wide as the pathway and at most 3 m, or wherever a doorway lies on it." "Openings are gaps in the per-edge boxes. They need no boolean geometry."
- **Wall height.** Spec §7: "Walls stand 1.2 m high in the preview so rooms read from above, with a toggle for full height."
- **Voids.** Spec §7: "A `void` cuts itself out of any slab on its floor that contains it, which gives automatic holes, and gets a 1.1 m balustrade around its edge."
- **Lifts, escalators and stairs.** Spec §7: "`PortalEndpoint` gains an optional `footprint` ring, stored as a jsonb column. A lift builds a shaft through every floor it stops at. An escalator or stair builds an inclined flight from the lower stop's footprint up to the next floor's elevation. It rises toward the end nearer the upper stop, and the inspector offers **Flip**."
- **Legibility.** Spec §7: "Pathways are drawn as flat strips in their kind's colour. Entrances and lift stops get markers. A bound room is tinted by its place's category."
- **Columns.** Spec §7: "The extractor finds them as small solid-filled rectangles, 0.3–1.5 m across, and proposes them as detail drafts named *Column*."
- **Labels are Part A's.** Room labels mount through `MapScene`'s `children` slot (spec §4). Part D builds no labels and must keep that slot wherever it edits `MapScene`.
- **The second builder's files.** `massing.ts`, `shell.ts` and `theme.ts` are imported, never edited. `LevelGroup.tsx`, `RoomMesh.tsx` and `MapScene.tsx` get only the hook-ins listed below. `cli/planL1.ts` is not edited (spec §7).
- **Shared files.** `@oth/model`'s `index.ts` and the renderer's `index.ts` are append-only. `db/schema.ts` gets two columns inside `portalEndpoints`, which the spec requires. The migration is generated in Task 7 only, just before that ship.
- **No new dependencies** in Tasks 1–7. Task 8 uses the `pdfjs-dist` that Part B pins.
- **Tests.** Test the geometry as pure functions over plain polygons. Where a test can check coordinates, never snapshot three.js objects. Run single files or one folder with `timeout 300 npx vitest run <path> --poolOptions.threads.maxThreads=2 --poolOptions.threads.minThreads=1`. **Never run the whole suite**; the controller does that at checkpoints. Typecheck with `npx tsc -b packages/<pkg>`.

## Review Focus

1. **A whole floor.** L1 has about 164 walled rooms, some with 33-point outlines, so about 2,500 edges. Pairing every edge with every other would stall the preview on each save. Merging sweeps edges sorted by x instead. Pinned in Task 1 by a 20 × 20 grid of rooms that must share exactly 760 walls.
2. **Outlines drawn either way round, or with a repeated point.** Traced rings are not normalised on the way in. Merging must not depend on winding, and a zero-length edge must build nothing. Pinned in Task 1.
3. **A pathway that runs along a wall, or stops just short of it.** Running along must open nothing. Stopping within 0.5 m of the wall must still open it. Near a wall's end, the opening is clamped and never produces a negative run. Pinned in Task 2.
4. **Deleted things.** Soft-deleted rooms, pathways, doorways, places, stops and portals must build nothing. The editor's model is live-only today, but the renderer must not depend on that. Pinned in Tasks 4, 5 and 6.
5. **Floors out of order.** A portal can join two floors at the same elevation, or ones whose ordinals and elevations disagree. That rise is zero or less: build no flight and don't crash. Pinned in Task 6.

```ts
/**
 * Stretches along a line, in metres from its start.
 *
 * Walls are cut into what stands and what is open by subtracting intervals,
 * never by boolean geometry: a doorway is a gap between two boxes, not a hole
 * cut out of one (spec §7).
 */
export type Interval = readonly [number, number];

/** Anything thinner than this is rounding, not wall. */
const EPSILON_M = 1e-9;

/**
 * What is left of [0, length] once every cut is taken out.
 *
 * Cuts may overlap, run past either end, come in any order, or be given
 * either way round. Pieces shorter than `minKeepM` are dropped, since a
 * sliver of wall between two openings is noise.
 */
export function subtractIntervals(length: number, cuts: readonly Interval[], minKeepM = 0): Interval[] {
  const sorted = cuts
    .map(([p, q]): Interval => [Math.max(0, Math.min(p, q)), Math.min(length, Math.max(p, q))])
    .filter(([from, to]) => to > from)
    .sort((x, y) => x[0] - y[0]);

  const kept: Interval[] = [];
  const keep = (from: number, to: number) => {
    if (to - from > EPSILON_M && to - from >= minKeepM) kept.push([from, to]);
  };

  let at = 0;
  for (const [from, to] of sorted) {
    keep(at, from);
    at = Math.max(at, to);
  }
  keep(at, length);
  return kept;
}
```

```ts
import type { Room, Vec2 } from "@oth/model";
import { subtractIntervals, type Interval } from "./intervals";

/**
 * Spec §7: neighbouring rooms' edges that are parallel and within 0.4 m of
 * each other are one wall, the drawing's own partition traced from both sides.
 */
export const MERGE_GAP_M = 0.4;
/** A wall's thickness when nothing says otherwise: the old shell's. */
export const DEFAULT_WALL_M = 0.15;
/** Edges within 5° of parallel can be one wall. A traced line wanders that much. */
const MERGE_ANGLE_SIN = Math.sin((5 * Math.PI) / 180);
/** A shorter shared stretch is two corners touching, not a wall. */
const MIN_SHARED_M = 0.1;
/** A shorter leftover is rounding at a corner. */
const MIN_PIECE_M = 0.05;

/**
 * One wall on the plan: its centre line, its thickness, and the rooms it
 * encloses. That is one room, or two when the wall is shared.
 */
export type WallPiece = { a: Vec2; b: Vec2; thicknessM: number; rooms: string[] };

type Edge = {
  a: Vec2; b: Vec2; roomId: string; len: number; ux: number; uy: number;
  minX: number; maxX: number; minY: number; maxY: number;
};

function edgesOf(room: Room): Edge[] {
  const edges: Edge[] = [];
  for (const ring of [room.footprint, ...room.holes]) {
    for (let i = 0; i < ring.length; i++) {
      const a = ring[i]!;
      const b = ring[(i + 1) % ring.length]!;
      const len = Math.hypot(b[0] - a[0], b[1] - a[1]);
      if (len < 1e-6) continue;
      edges.push({
        a, b, roomId: room.id, len, ux: (b[0] - a[0]) / len, uy: (b[1] - a[1]) / len,
        minX: Math.min(a[0], b[0]), maxX: Math.max(a[0], b[0]),
        minY: Math.min(a[1], b[1]), maxY: Math.max(a[1], b[1]),
      });
    }
  }
  return edges;
}

/** Metres along the edge to the foot of `p`. */
const along = (e: Edge, p: Vec2) => (p[0] - e.a[0]) * e.ux + (p[1] - e.a[1]) * e.uy;
const pointAt = (e: Edge, t: number): Vec2 => [e.a[0] + e.ux * t, e.a[1] + e.uy * t];
const midpoint = (p: Vec2, q: Vec2): Vec2 => [(p[0] + q[0]) / 2, (p[1] + q[1]) / 2];
const distance = (p: Vec2, q: Vec2) => Math.hypot(p[0] - q[0], p[1] - q[1]);

/**
 * Every room's boundary as wall pieces, with one wall wherever two rooms meet.
 *
 * Where two rooms share a boundary the old shell stood two walls, one per
 * room, and the drawing's partition read twice. Here the stretch two edges
 * share becomes one piece midway between them, owned by both. Whatever is
 * left of each edge stays a wall of its own room.
 */
export function wallPieces(rooms: readonly Room[]): WallPiece[] {
  // Sorted west to east, so each edge meets only the few that overlap it in x:
  // a whole floor is thousands of edges, and every pair would be millions.
  const edges = rooms.flatMap(edgesOf).sort((p, q) => p.minX - q.minX);
  const covered: Interval[][] = edges.map(() => []);
  const pieces: WallPiece[] = [];

  for (let i = 0; i < edges.length; i++) {
    const e = edges[i]!;
    for (let j = i + 1; j < edges.length; j++) {
      const f = edges[j]!;
      if (f.minX > e.maxX + MERGE_GAP_M) break;
      if (f.roomId === e.roomId) continue;
      if (f.minY > e.maxY + MERGE_GAP_M || f.maxY < e.minY - MERGE_GAP_M) continue;
      if (Math.abs(e.ux * f.uy - e.uy * f.ux) > MERGE_ANGLE_SIN) continue;

      // The stretch of e that f runs alongside.
      const s0 = along(e, f.a);
      const s1 = along(e, f.b);
      const t0 = Math.max(0, Math.min(s0, s1));
      const t1 = Math.min(e.len, Math.max(s0, s1));
      if (t1 - t0 < MIN_SHARED_M) continue;

      const p0 = pointAt(e, t0);
      const p1 = pointAt(e, t1);
      const q0 = pointAt(f, along(f, p0));
      const q1 = pointAt(f, along(f, p1));
      const gap0 = distance(p0, q0);
      const gap1 = distance(p1, q1);
      if (gap0 > MERGE_GAP_M || gap1 > MERGE_GAP_M) continue;

      pieces.push({
        a: midpoint(p0, q0),
        b: midpoint(p1, q1),
        // Coincident edges have no gap to measure. They still get a wall.
        thicknessM: Math.max((gap0 + gap1) / 2, DEFAULT_WALL_M),
        rooms: [e.roomId, f.roomId],
      });
      covered[i]!.push([t0, t1]);
      covered[j]!.push([along(f, q0), along(f, q1)]);
    }
  }

  edges.forEach((e, i) => {
    for (const [t0, t1] of subtractIntervals(e.len, covered[i]!, MIN_PIECE_M)) {
      pieces.push({ a: pointAt(e, t0), b: pointAt(e, t1), thicknessM: DEFAULT_WALL_M, rooms: [e.roomId] });
    }
  });
  return pieces;
}
```

```ts
import { distancePointToSegment, type Doorway, type Pathway, type Vec2 } from "@oth/model";
import { subtractIntervals, type Interval } from "./intervals";
import type { WallPiece } from "./wallPlan";

/** Spec §7: an opening is as wide as the pathway through it, and at most 3 m. */
export const MAX_PATH_OPENING_M = 3;
/** A pathway drawn up to a wall that stops this short of it still goes through. */
export const PATH_REACH_M = 0.5;
/** A doorway this far off a wall's face still lies on it: traced lines wander. */
const DOORWAY_SLACK_M = 0.3;
/**
 * How near a pathway must pass for a closed room to get a front door onto it.
 * The same 3 m as the `room.noAccess` check (ROOM_ACCESS_M in the model's
 * access rule), so a room the validator calls reachable is never a closed box.
 */
export const SHOPFRONT_REACH_M = 3;
/** A shorter stand of wall between two openings is dropped. */
const MIN_RUN_M = 0.05;

type Frame = { a: Vec2; len: number; ux: number; uy: number };

function frameOf(piece: WallPiece): Frame | null {
  const dx = piece.b[0] - piece.a[0];
  const dy = piece.b[1] - piece.a[1];
  const len = Math.hypot(dx, dy);
  return len < 1e-9 ? null : { a: piece.a, len, ux: dx / len, uy: dy / len };
}

const along = (f: Frame, p: Vec2) => (p[0] - f.a[0]) * f.ux + (p[1] - f.a[1]) * f.uy;
const across = (f: Frame, p: Vec2) => Math.abs((p[0] - f.a[0]) * f.uy - (p[1] - f.a[1]) * f.ux);
const pointAt = (f: Frame, t: number): Vec2 => [f.a[0] + f.ux * t, f.a[1] + f.uy * t];

/** A pathway's stretches, with its two ends pushed out by PATH_REACH_M. */
function reachingSegments(polyline: readonly Vec2[]): Array<[Vec2, Vec2]> {
  const segments: Array<[Vec2, Vec2]> = [];
  for (let i = 0; i + 1 < polyline.length; i++) {
    let p = polyline[i]!;
    let q = polyline[i + 1]!;
    const len = Math.hypot(q[0] - p[0], q[1] - p[1]);
    if (len < 1e-9) continue;
    const ux = (q[0] - p[0]) / len;
    const uy = (q[1] - p[1]) / len;
    if (i === 0) p = [p[0] - ux * PATH_REACH_M, p[1] - uy * PATH_REACH_M];
    if (i + 2 === polyline.length) q = [q[0] + ux * PATH_REACH_M, q[1] + uy * PATH_REACH_M];
    segments.push([p, q]);
  }
  return segments;
}

/** Metres along the piece where p→q crosses its centre line, or null. Parallel never crosses. */
function crossingAt(f: Frame, p: Vec2, q: Vec2): number | null {
  const rx = q[0] - p[0];
  const ry = q[1] - p[1];
  const sx = f.ux * f.len;
  const sy = f.uy * f.len;
  const denom = rx * sy - ry * sx;
  if (Math.abs(denom) < 1e-9 * Math.hypot(rx, ry) * f.len) return null;
  const wx = f.a[0] - p[0];
  const wy = f.a[1] - p[1];
  const t = (wx * sy - wy * sx) / denom;
  const u = (wx * ry - wy * rx) / denom;
  if (t < 0 || t > 1 || u < 0 || u > 1) return null;
  return u * f.len;
}

export function pathwayOpenings(piece: WallPiece, pathways: readonly Pathway[]): Interval[] {
  const f = frameOf(piece);
  if (!f) return [];
  const openings: Interval[] = [];
  for (const pathway of pathways) {
    const half = Math.min(pathway.widthM, MAX_PATH_OPENING_M) / 2;
    for (const [p, q] of reachingSegments(pathway.polyline)) {
      const at = crossingAt(f, p, q);
      if (at !== null) openings.push([at - half, at + half]);
    }
  }
  return openings;
}

export function doorwayOpenings(piece: WallPiece, doorways: readonly Doorway[]): Interval[] {
  const f = frameOf(piece);
  if (!f) return [];
  const near = piece.thicknessM / 2 + DOORWAY_SLACK_M;
  const openings: Interval[] = [];
  for (const doorway of doorways) {
    const [d0, d1] = doorway.segment;
    if (across(f, d0) > near || across(f, d1) > near) continue;
    let from = Math.min(along(f, d0), along(f, d1));
    let to = Math.max(along(f, d0), along(f, d1));
    if (to < 0 || from > f.len) continue;
    if (to - from < doorway.widthM) {
      const middle = (from + to) / 2;
      from = middle - doorway.widthM / 2;
      to = middle + doorway.widthM / 2;
    }
    openings.push([from, to]);
  }
  return openings;
}

/**
 * The point of the piece nearest a pathway stretch, and how near.
 *
 * Two segments that do not cross are nearest at an end of one of them, so
 * four candidates are enough. Where several are equally near, as along a
 * parallel pathway, the door goes in the middle of them.
 */
function nearestOnPiece(f: Frame, p: Vec2, q: Vec2): { t: number; distance: number } {
  const clamp = (t: number) => Math.max(0, Math.min(f.len, t));
  const ts = [0, f.len, clamp(along(f, p)), clamp(along(f, q))];
  const ds = ts.map(t => distancePointToSegment(pointAt(f, t), p, q));
  const distance = Math.min(...ds);
  const ties = ts.filter((_, i) => ds[i]! - distance < 1e-6);
  return { t: ties.reduce((sum, t) => sum + t, 0) / ties.length, distance };
}

/** Where a closed room's front door goes on this piece, if a pathway passes within reach. */
export function shopfrontOpening(
  piece: WallPiece, pathways: readonly Pathway[],
): { interval: Interval; distance: number } | null {
  const f = frameOf(piece);
  if (!f) return null;
  let best: { interval: Interval; distance: number } | null = null;
  for (const pathway of pathways) {
    const width = Math.min(pathway.widthM, MAX_PATH_OPENING_M, f.len);
    for (let i = 0; i + 1 < pathway.polyline.length; i++) {
      const p = pathway.polyline[i]!;
      const q = pathway.polyline[i + 1]!;
      const near = nearestOnPiece(f, p, q);
      if (near.distance > SHOPFRONT_REACH_M) continue;
      // Slid back inside the wall rather than cut short at its end, then
      // ranked by where the door actually is: a side wall's corner can be as
      // near as the front, but a door slid along it is not.
      const middle = Math.max(width / 2, Math.min(f.len - width / 2, near.t));
      const distance = distancePointToSegment(pointAt(f, middle), p, q);
      if (best === null || distance < best.distance) {
        best = { interval: [middle - width / 2, middle + width / 2], distance };
      }
    }
  }
  return best;
}

/**
 * The walls that stand, once every opening is cut out of them.
 *
 * Pathways and doorways open the walls they cross. A walled room that
 * nothing opens, but that a pathway passes within 3 m of, gets one front door
 * facing that pathway, on a wall of its own and never one it shares.
 */
export function wallRuns(
  pieces: readonly WallPiece[], pathways: readonly Pathway[], doorways: readonly Doorway[],
): WallPiece[] {
  const cuts: Interval[][] = pieces.map(p => [...pathwayOpenings(p, pathways), ...doorwayOpenings(p, doorways)]);

  const opened = new Set<string>();
  const ownPieces = new Map<string, number[]>();
  pieces.forEach((p, i) => {
    if (cuts[i]!.length > 0) for (const id of p.rooms) opened.add(id);
    if (p.rooms.length === 1) {
      const id = p.rooms[0]!;
      ownPieces.set(id, [...(ownPieces.get(id) ?? []), i]);
    }
  });

  for (const [roomId, indices] of ownPieces) {
    if (opened.has(roomId)) continue;
    let best: { index: number; interval: Interval; distance: number } | null = null;
    for (const index of indices) {
      const door = shopfrontOpening(pieces[index]!, pathways);
      if (door && (best === null || door.distance < best.distance)) best = { index, ...door };
    }
    if (best) cuts[best.index]!.push(best.interval);
  }

  const runs: WallPiece[] = [];
  pieces.forEach((p, i) => {
    const f = frameOf(p);
    if (!f) return;
    for (const [t0, t1] of subtractIntervals(f.len, cuts[i]!, MIN_RUN_M)) {
      runs.push({ a: pointAt(f, t0), b: pointAt(f, t1), thicknessM: p.thicknessM, rooms: p.rooms });
    }
  });
  return runs;
}
```

```ts
import {
  pointInPolygon, pointInRing, segmentsProperlyIntersect,
  type Ring, type Room, type RoomKind, type Vec2,
} from "@oth/model";

/** Spec §7: a 1.1 m balustrade around a void's edge. */
export const BALUSTRADE_HEIGHT_M = 1.1;
/** Thin: glass and a handrail, not a wall. */
export const BALUSTRADE_THICKNESS_M = 0.08;

/** The kinds that are floor. A detail stands on the floor; a void is the lack of one. */
const FLOORED: ReadonlySet<RoomKind> = new Set<RoomKind>(["room", "area", "service"]);

/** A stretch of balustrade. It has the same shape as a wall piece, so one builder stands both. */
export type Rail = { a: Vec2; b: Vec2; thicknessM: number; rooms: string[] };

function edgesCross(p: Ring, q: Ring): boolean {
  for (let i = 0; i < p.length; i++) {
    const a = p[i]!;
    const b = p[(i + 1) % p.length]!;
    for (let j = 0; j < q.length; j++) {
      if (segmentsProperlyIntersect(a, b, q[j]!, q[(j + 1) % q.length]!)) return true;
    }
  }
  return false;
}

/**
 * Whether `inner` lies wholly on the slab's floor: inside its outline and
 * clear of its holes.
 *
 * Every corner inside is not enough, since an edge can still cross a notch
 * of an L-shaped floor, and a hole already there must not overlap the new
 * one. Either would make a slab its triangulation cannot draw. A void that
 * only touches the slab's edge is left uncut rather than guessed at.
 */
export function floorContains(slab: Room, inner: Ring): boolean {
  if (!inner.every(p => pointInPolygon(p, slab.footprint, slab.holes))) return false;
  if (edgesCross(inner, slab.footprint)) return false;
  for (const hole of slab.holes) {
    if (edgesCross(inner, hole)) return false;
    if (hole.some(p => pointInRing(p, inner))) return false;
  }
  return true;
}

/**
 * Spec §7: a void cuts itself out of any slab on its floor that contains it.
 * Keyed by the slab's room id; each value is extra holes for that slab.
 */
export function voidHoles(rooms: readonly Room[]): Map<string, Room["holes"]> {
  const holes = new Map<string, Room["holes"]>();
  for (const opening of rooms.filter(r => r.kind === "void")) {
    for (const slab of rooms) {
      if (slab.levelId !== opening.levelId || !FLOORED.has(slab.kind)) continue;
      if (!floorContains(slab, opening.footprint)) continue;
      holes.set(slab.id, [...(holes.get(slab.id) ?? []), opening.footprint]);
    }
  }
  return holes;
}

/** A balustrade along every edge of every void. */
export function balustradeRuns(rooms: readonly Room[]): Rail[] {
  const rails: Rail[] = [];
  for (const opening of rooms) {
    if (opening.kind !== "void") continue;
    const ring = opening.footprint;
    for (let i = 0; i < ring.length; i++) {
      const a = ring[i]!;
      const b = ring[(i + 1) % ring.length]!;
      if (Math.hypot(b[0] - a[0], b[1] - a[1]) < 1e-6) continue;
      rails.push({ a, b, thicknessM: BALUSTRADE_THICKNESS_M, rooms: [opening.id] });
    }
  }
  return rails;
}
```

```ts
import type { Vec2 } from "@oth/model";
import * as THREE from "three";
import { modelToThree } from "./coords";

/**
 * A block standing on the floor: a wall, a rail, a step or a shaft side.
 *
 * Its centre line runs a→b on the plan, it is `thicknessM` across that line,
 * and it stands from `baseM` to `topM` above the level's floor.
 */
export type Block = { a: Vec2; b: Vec2; thicknessM: number; baseM: number; topM: number };

/**
 * All the blocks as one geometry, so a floor's walls are one draw call.
 * The meshes use a double-sided material, so the winding of the faces doesn't matter.
 */
export function blocksGeometry(blocks: readonly Block[]): THREE.BufferGeometry {
  const positions: number[] = [];
  const quad = (
    p: [number, number, number], q: [number, number, number],
    r: [number, number, number], s: [number, number, number],
  ) => {
    positions.push(...p, ...q, ...r, ...p, ...r, ...s);
  };

  for (const block of blocks) {
    const dx = block.b[0] - block.a[0];
    const dy = block.b[1] - block.a[1];
    const len = Math.hypot(dx, dy);
    if (len < 1e-6 || block.topM <= block.baseM) continue;
    const half = block.thicknessM / 2;
    const nx = (-dy / len) * half;
    const ny = (dx / len) * half;
    const corners: Array<[number, number]> = [
      [block.a[0] + nx, block.a[1] + ny], [block.b[0] + nx, block.b[1] + ny],
      [block.b[0] - nx, block.b[1] - ny], [block.a[0] - nx, block.a[1] - ny],
    ];
    const low = corners.map(([x, y]) => modelToThree(x, y, block.baseM));
    const high = corners.map(([x, y]) => modelToThree(x, y, block.topM));
    for (let i = 0; i < 4; i++) {
      const j = (i + 1) % 4;
      quad(low[i]!, low[j]!, high[j]!, high[i]!);
    }
    quad(high[0]!, high[1]!, high[2]!, high[3]!);
    quad(low[3]!, low[2]!, low[1]!, low[0]!);
  }

  const geometry = new THREE.BufferGeometry();
  geometry.setAttribute("position", new THREE.Float32BufferAttribute(positions, 3));
  geometry.computeVertexNormals();
  return geometry;
}
```

```ts
import { live, type MapModel, type Room } from "@oth/model";
import { massingOf } from "./massing";
import { wallRuns } from "./openings";
import { balustradeRuns, voidHoles } from "./voids";
import { wallPieces, type WallPiece } from "./wallPlan";

/** Spec §7: walls stand 1.2 m high in the preview so rooms read from above. */
export const LOW_WALL_M = 1.2;

/**
 * Names the drawing gives a flight of steps. L1's escalators were imported
 * as rooms (spec §7), and walled they read as closed boxes. Anchored and
 * whole-word, so "Stairway Café" is still a room. Task 7's conversion
 * replaces this for any space someone converts.
 */
const FLIGHT_NAME = /^(escalators?|staircase|stairs?)\b/i;

/** Everything Part D builds on one level, as plain data. */
export type LevelStructure = {
  /** Walls that stand, already merged and opened. */
  walls: WallPiece[];
  balustrades: WallPiece[];
  /** Voids to cut from each floor room's slab. */
  holesByRoom: ReadonlyMap<string, Room["holes"]>;
  heightByRoom: ReadonlyMap<string, number>;
};

export function levelStructure(model: MapModel, levelId: string): LevelStructure {
  const rooms = live(model.rooms).filter(r => r.levelId === levelId);
  const walled = rooms.filter(r => massingOf(r) === "shell" && !FLIGHT_NAME.test(r.nameEn.trim()));
  const pathways = live(model.pathways).filter(p => p.levelId === levelId);
  const doorways = live(model.doorways).filter(d => d.levelId === levelId);
  return {
    walls: wallRuns(wallPieces(walled), pathways, doorways),
    balustrades: balustradeRuns(rooms),
    holesByRoom: voidHoles(rooms),
    heightByRoom: new Map(rooms.map(r => [r.id, r.heightM])),
  };
}

/** How tall a wall stands: 1.2 m, or at full height as tall as the taller room it encloses. */
export function wallTop(piece: WallPiece, heights: ReadonlyMap<string, number>, fullHeight: boolean): number {
  const own = Math.max(...piece.rooms.map(id => heights.get(id) ?? LOW_WALL_M));
  return fullHeight ? own : Math.min(LOW_WALL_M, own);
}
```

```tsx
import { useEffect, useMemo } from "react";
import * as THREE from "three";
import { blocksGeometry, type Block } from "./blocks";
import { wallTop, type LevelStructure } from "./structure";
import { roomColor, wallColor } from "./theme";
import { BALUSTRADE_HEIGHT_M } from "./voids";
import type { WallPiece } from "./wallPlan";

/** A grey-blue a shade off the walls, so a balustrade reads as a rail and not a wall. */
const BALUSTRADE_COLOUR = "#9fb3c8";

/**
 * A level's walls and balustrades. The walls of the selected room are drawn
 * in the selection colour, as its shell used to be. Walls take no clicks:
 * a wall can belong to two rooms, and the floor says which one you meant.
 */
export function StructureMesh({ structure, fullHeight, ghosted, selectedId }: {
  structure: LevelStructure;
  fullHeight: boolean;
  ghosted: boolean;
  selectedId: string | null;
}) {
  const { plain, picked } = useMemo(() => {
    const block = (w: WallPiece): Block => ({ ...w, baseM: 0, topM: wallTop(w, structure.heightByRoom, fullHeight) });
    const mine = (w: WallPiece) => selectedId !== null && w.rooms.includes(selectedId);
    return {
      plain: blocksGeometry(structure.walls.filter(w => !mine(w)).map(block)),
      picked: blocksGeometry(structure.walls.filter(mine).map(block)),
    };
  }, [structure, fullHeight, selectedId]);
  const rails = useMemo(
    () => blocksGeometry(structure.balustrades.map(r => ({ ...r, baseM: 0, topM: BALUSTRADE_HEIGHT_M }))),
    [structure],
  );
  useEffect(() => () => {
    plain.dispose();
    picked.dispose();
  }, [plain, picked]);
  useEffect(() => () => rails.dispose(), [rails]);

  return (
    <group>
      <mesh geometry={plain} castShadow receiveShadow>
        <meshStandardMaterial
          color={wallColor("room", { ghosted })}
          transparent={ghosted}
          opacity={ghosted ? 0.25 : 1}
          side={THREE.DoubleSide}
        />
      </mesh>
      {!ghosted && (
        <mesh geometry={picked} castShadow>
          <meshStandardMaterial color={roomColor("room", { selected: true })} side={THREE.DoubleSide} />
        </mesh>
      )}
      <mesh geometry={rails}>
        <meshStandardMaterial color={BALUSTRADE_COLOUR} transparent opacity={ghosted ? 0.2 : 0.6} side={THREE.DoubleSide} />
      </mesh>
    </group>
  );
```

```ts
import { live, type MapModel, type Pathway, type PathwayKind, type Vec2 } from "@oth/model";

/** The plan's colour for a pathway with no kind (PathwayShape's default). */
export const DEFAULT_PATHWAY_COLOUR = "#38bdf8";

export type Quad = readonly [Vec2, Vec2, Vec2, Vec2];

/** One flat quad per stretch of the pathway, as wide as it. */
export function stripQuads(polyline: readonly Vec2[], widthM: number): Quad[] {
  const half = widthM / 2;
  const quads: Quad[] = [];
  for (let i = 0; i + 1 < polyline.length; i++) {
    const p = polyline[i]!;
    const q = polyline[i + 1]!;
    const len = Math.hypot(q[0] - p[0], q[1] - p[1]);
    if (len < 1e-6) continue;
    const nx = (-(q[1] - p[1]) / len) * half;
    const ny = ((q[0] - p[0]) / len) * half;
    quads.push([[p[0] + nx, p[1] + ny], [q[0] + nx, q[1] + ny], [q[0] - nx, q[1] - ny], [p[0] - nx, p[1] - ny]]);
  }
  return quads;
}

function colourOf(pathway: Pathway, kinds: readonly PathwayKind[]): string {
  return kinds.find(k => k.id === pathway.kindId)?.colorHex ?? DEFAULT_PATHWAY_COLOUR;
}

/** Spec §7: pathways as flat strips in their kind's colour, one group per colour so each is one mesh. */
export function pathwayStrips(model: MapModel, levelId: string): Array<{ colour: string; quads: Quad[] }> {
  const kinds = live(model.pathwayKinds);
  const byColour = new Map<string, Quad[]>();
  for (const pathway of live(model.pathways)) {
    if (pathway.levelId !== levelId) continue;
    const colour = colourOf(pathway, kinds);
    byColour.set(colour, [...(byColour.get(colour) ?? []), ...stripQuads(pathway.polyline, pathway.widthM)]);
  }
  return [...byColour].map(([colour, quads]) => ({ colour, quads }));
}
```

```ts
import { live, type MapModel, type PortalKind, type Vec2 } from "@oth/model";

export type MarkerKind = "entrance" | PortalKind;
export type Marker = { id: string; kind: MarkerKind; point: Vec2 };
export type MarkerShape = "cone" | "box" | "cylinder" | "octahedron";

/**
 * Each kind has its own shape as well as its own colour, so colour is never
 * the only difference. An entrance is a cone pointing down into the building,
 * a lift is a box, an escalator a drum, and stairs and ramps an octahedron.
 */
export const MARKER_STYLE: Record<MarkerKind, { colour: string; shape: MarkerShape }> = {
  entrance: { colour: "#15803d", shape: "cone" },
  lift: { colour: "#1d4ed8", shape: "box" },
  escalator: { colour: "#b45309", shape: "cylinder" },
  stair: { colour: "#7c3aed", shape: "octahedron" },
  ramp: { colour: "#7c3aed", shape: "octahedron" },
};

/** Spec §7: entrances and lift stops get markers. A stop whose lift is gone gets none. */
export function levelMarkers(model: MapModel, levelId: string): Marker[] {
  const portals = new Map(live(model.portals).map(p => [p.id, p]));
  const markers: Marker[] = [];
  for (const entrance of live(model.entrances)) {
    if (entrance.levelId === levelId) markers.push({ id: entrance.id, kind: "entrance", point: entrance.point });
  }
  for (const stop of live(model.portalEndpoints)) {
    const portal = portals.get(stop.portalId);
    if (stop.levelId === levelId && portal) markers.push({ id: stop.id, kind: portal.kind, point: stop.point });
  }
  return markers;
}
```

```ts
import { live, type MapModel, type TenantCategory } from "@oth/model";

/**
 * Light tints, so a tinted floor still reads as floor and walls stay darker.
 * Each differs from the plain room colour (theme.ts's #e7ddc7). Part A's
 * labels name the place; the tint only groups like with like.
 */
export const CATEGORY_TINT: Record<TenantCategory, string> = {
  government: "#c7d6ea",
  healthcare: "#f0c4c4",
  community: "#d8cbe9",
  retail: "#f2d59b",
  lifestyle: "#f3c9dd",
  sports: "#c3e0bf",
  facility: "#cfd6dc",
};

/**
 * Spec §7: a bound room is tinted by its place's category. When two places
 * are bound to one room, the one first by id wins, so the tint never flickers
 * between saves.
 */
export function roomTints(model: MapModel, levelId: string): Map<string, string> {
  const onLevel = new Set(live(model.rooms).filter(r => r.levelId === levelId).map(r => r.id));
  const tints = new Map<string, string>();
  const bound = live(model.places)
    .filter(p => p.roomId !== undefined && onLevel.has(p.roomId))
    .sort((a, b) => a.id.localeCompare(b.id));
  for (const place of bound) {
    if (!tints.has(place.roomId!)) tints.set(place.roomId!, CATEGORY_TINT[place.category]);
  }
  return tints;
}
```

```ts
/** Flat quads at one height, for pathway strips. */
export function quadsGeometry(quads: readonly (readonly [Vec2, Vec2, Vec2, Vec2])[], heightM: number): THREE.BufferGeometry {
  const positions: number[] = [];
  for (const quad of quads) {
    const [a, b, c, d] = quad.map(([x, y]) => modelToThree(x, y, heightM));
    positions.push(...a!, ...b!, ...c!, ...a!, ...c!, ...d!);
  }
  const geometry = new THREE.BufferGeometry();
  geometry.setAttribute("position", new THREE.Float32BufferAttribute(positions, 3));
  geometry.computeVertexNormals();
  return geometry;
}
```

```ts
import type { Ring, Vec2 } from "../primitives";

/**
 * A rectangle at any angle: centre, the unit axis along its long side, and
 * half its length and width. The axis points east, or north when the
 * rectangle stands exactly upright, so the same outline always gives the
 * same rectangle.
 */
export type OrientedRect = { centre: Vec2; axis: Vec2; halfLength: number; halfWidth: number };

function cross(o: Vec2, a: Vec2, b: Vec2): number {
  return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0]);
}

/** Andrew's monotone chain; counter-clockwise, no repeated point. */
export function convexHull(points: readonly Vec2[]): Vec2[] {
  const pts = [...points].sort((a, b) => a[0] - b[0] || a[1] - b[1]);
  if (pts.length <= 2) return pts;
  const lower: Vec2[] = [];
  for (const p of pts) {
    while (lower.length >= 2 && cross(lower[lower.length - 2]!, lower[lower.length - 1]!, p) <= 0) lower.pop();
    lower.push(p);
  }
  const upper: Vec2[] = [];
  for (let i = pts.length - 1; i >= 0; i--) {
    const p = pts[i]!;
    while (upper.length >= 2 && cross(upper[upper.length - 2]!, upper[upper.length - 1]!, p) <= 0) upper.pop();
    upper.push(p);
  }
  return [...lower.slice(0, -1), ...upper.slice(0, -1)];
}

function eastward(a: Vec2): Vec2 {
  const flip = a[0] < -1e-9 || (Math.abs(a[0]) <= 1e-9 && a[1] < 0);
  // + 0 turns -0 into 0, so an upright axis compares equal to [0, 1].
  return flip ? [-a[0] + 0, -a[1] + 0] : [a[0] + 0, a[1] + 0];
}

/**
 * The smallest rectangle around an outline. The best rectangle has a side
 * along an edge of the convex hull, so trying each hull edge is exact. It
 * turns a traced escalator into the flight's length, width and direction.
 */
export function minAreaRect(ring: Ring): OrientedRect {
  const hull = convexHull(ring);
  let best: OrientedRect | null = null;
  let bestArea = Infinity;
  for (let i = 0; i < hull.length; i++) {
    const p = hull[i]!;
    const q = hull[(i + 1) % hull.length]!;
    const len = Math.hypot(q[0] - p[0], q[1] - p[1]);
    if (len < 1e-12) continue;
    const u: Vec2 = [(q[0] - p[0]) / len, (q[1] - p[1]) / len];
    const v: Vec2 = [-u[1], u[0]];
    let minU = Infinity;
    let maxU = -Infinity;
    let minV = Infinity;
    let maxV = -Infinity;
    for (const h of hull) {
      const a = h[0] * u[0] + h[1] * u[1];
      const b = h[0] * v[0] + h[1] * v[1];
      minU = Math.min(minU, a);
      maxU = Math.max(maxU, a);
      minV = Math.min(minV, b);
      maxV = Math.max(maxV, b);
    }
    const area = (maxU - minU) * (maxV - minV);
    if (area >= bestArea - 1e-12) continue;
    bestArea = area;
    const cu = (minU + maxU) / 2;
    const cv = (minV + maxV) / 2;
    const long = maxU - minU >= maxV - minV;
    best = {
      centre: [u[0] * cu + v[0] * cv, u[1] * cu + v[1] * cv],
      axis: eastward(long ? u : v),
      halfLength: (long ? maxU - minU : maxV - minV) / 2,
      halfWidth: (long ? maxV - minV : maxU - minU) / 2,
    };
  }
  return best ?? { centre: ring[0] ?? [0, 0], axis: [1, 0], halfLength: 0, halfWidth: 0 };
}

export function rectCorners(r: OrientedRect): Vec2[] {
  const [ux, uy] = r.axis;
  const [vx, vy] = [-uy, ux];
  const [cx, cy] = r.centre;
  const l = r.halfLength;
  const w = r.halfWidth;
  return [
    [cx - ux * l - vx * w, cy - uy * l - vy * w],
    [cx + ux * l - vx * w, cy + uy * l - vy * w],
    [cx + ux * l + vx * w, cy + uy * l + vy * w],
    [cx - ux * l + vx * w, cy - uy * l + vy * w],
  ];
}
```

```ts
import {
  live, minAreaRect,
  type Level, type MapModel, type OrientedRect, type PortalEndpoint, type PortalKind, type Ring, type Vec2,
} from "@oth/model";
import type { Block } from "./blocks";

/** A lift car's shaft, when the drawing gives no outline. */
export const DEFAULT_SHAFT_M = 2.4;
/** A comfortable riser; escalator steps are close to it. */
export const RISER_M = 0.17;
/** Thin, so a shaft reads as glass and shows the lift inside. */
const SHAFT_WALL_M = 0.12;

export type Shaft = { portalId: string; ring: Ring; heightM: number };
export type Flight = { portalId: string; kind: PortalKind; steps: Block[] };

/** A portal's live stops on live floors, lowest floor first. */
export function stopsInOrder(model: MapModel, portalId: string): Array<{ stop: PortalEndpoint; level: Level }> {
  const levels = new Map(live(model.levels).map(l => [l.id, l]));
  return live(model.portalEndpoints)
    .filter(e => e.portalId === portalId && levels.has(e.levelId))
    .map(stop => ({ stop, level: levels.get(stop.levelId)! }))
    .sort((a, b) => a.level.ordinal - b.level.ordinal);
}

export function nextStopAbove(model: MapModel, endpoint: PortalEndpoint): PortalEndpoint | null {
  const stops = stopsInOrder(model, endpoint.portalId);
  const i = stops.findIndex(s => s.stop.id === endpoint.id);
  return i >= 0 ? stops[i + 1]?.stop ?? null : null;
}

/**
 * Spec §7: a flight rises toward the end nearer the upper stop. With the
 * upper stop at the middle, which is what clicking the dashed outline
 * places, there is no evidence either way: it rises toward the axis's end,
 * and Flip is how a person says otherwise.
 */
export function risesTowardPositive(rect: OrientedRect, upperPoint: Vec2 | null, flipped: boolean): boolean {
  let positive = true;
  if (upperPoint) {
    const t = (upperPoint[0] - rect.centre[0]) * rect.axis[0] + (upperPoint[1] - rect.centre[1]) * rect.axis[1];
    if (Math.abs(t) > 1e-6) positive = t > 0;
  }
  return flipped ? !positive : positive;
}

/**
 * A flight as stepped blocks standing on the floor, from the low end to the
 * high one. The top step is level with the floor above. Each block runs
 * across the flight, as deep as one tread.
 */
export function flightSteps(rect: OrientedRect, riseM: number, towardPositive: boolean, riserM = RISER_M): Block[] {
  const count = Math.max(1, Math.ceil(riseM / riserM - 1e-9));
  const depth = (2 * rect.halfLength) / count;
  const dir = towardPositive ? 1 : -1;
  const [ux, uy] = rect.axis;
  const vx = -uy * rect.halfWidth;
  const vy = ux * rect.halfWidth;
  const steps: Block[] = [];
  for (let i = 0; i < count; i++) {
    const s = dir * (-rect.halfLength + depth * (i + 0.5));
    const cx = rect.centre[0] + ux * s;
    const cy = rect.centre[1] + uy * s;
    steps.push({ a: [cx - vx, cy - vy], b: [cx + vx, cy + vy], thicknessM: depth, baseM: 0, topM: (riseM * (i + 1)) / count });
  }
  return steps;
}

function squareAround(point: Vec2, size: number): Ring {
  const h = size / 2;
  return [[point[0] - h, point[1] - h], [point[0] + h, point[1] - h], [point[0] + h, point[1] + h], [point[0] - h, point[1] + h]];
}

/** A shaft's sides, as blocks on its outline. */
export function shaftBlocks(shaft: Shaft): Block[] {
  const blocks: Block[] = [];
  const ring = shaft.ring;
  for (let i = 0; i < ring.length; i++) {
    blocks.push({ a: ring[i]!, b: ring[(i + 1) % ring.length]!, thicknessM: SHAFT_WALL_M, baseM: 0, topM: shaft.heightM });
  }
  return blocks;
}

/**
 * What the lifts, escalators and stairs build on one level.
 *
 * A lift builds a shaft at every stop, one storey tall, so the stops stack
 * into one shaft. An escalator, stair or ramp builds a flight on the lower
 * of each pair of stops, from its outline (or the upper stop's) up to the
 * upper floor. With no outline at either stop, or no rise between the floors,
 * it builds no flight and is shown only by its markers.
 */
export function portalParts(model: MapModel, levelId: string): { shafts: Shaft[]; flights: Flight[] } {
  const shafts: Shaft[] = [];
  const flights: Flight[] = [];
  for (const portal of live(model.portals)) {
    const stops = stopsInOrder(model, portal.id);
    if (portal.kind === "lift") {
      for (const { stop, level } of stops) {
        if (stop.levelId !== levelId) continue;
        shafts.push({ portalId: portal.id, ring: stop.footprint ?? squareAround(stop.point, DEFAULT_SHAFT_M), heightM: level.heightM });
      }
      continue;
    }
    for (let i = 0; i + 1 < stops.length; i++) {
      const lower = stops[i]!;
      const upper = stops[i + 1]!;
      if (lower.stop.levelId !== levelId) continue;
      const outline = lower.stop.footprint ?? upper.stop.footprint;
      const rise = upper.level.elevationM - lower.level.elevationM;
      if (!outline || rise <= 0) continue;
      const rect = minAreaRect(outline);
      if (rect.halfLength <= 0) continue;
      const toward = risesTowardPositive(rect, upper.stop.point, lower.stop.flipped);
      flights.push({ portalId: portal.id, kind: portal.kind, steps: flightSteps(rect, rise, toward) });
    }
  }
  return { shafts, flights };
}
```

**How a stop gets its outline.** The spec gives the field but not the gesture. In the room inspector, **Lift · Escalator · Stairs** turns the selected space into a stop:

- The space stays, as a walkable area with its name, so routing can reach the stop and Part A's label still names it.

This is how L1's *Escalator – nn* rooms are converted in the app (spec §7). A space with a detail or void kind isn't offered it.

```ts
import {
  bboxOfRing, live, pointInPolygon, ringCentroid,
  type MapModel, type Ring, type Room, type Vec2,
} from "@oth/model";
import { portalEndpointAt } from "../flow/placePoint";

export type StopKind = "lift" | "escalator" | "stair";

/**
 * A point inside the ring and clear of its holes. The centroid if that is
 * inside, and otherwise the middle of the widest span across the outline at
 * one of a few heights. An L-shaped outline's centroid is outside it.
 */
export function insidePoint(ring: Ring, holes: readonly Ring[] = []): Vec2 {
  const centroid = ringCentroid(ring);
  if (pointInPolygon(centroid, ring, holes)) return centroid;
  const b = bboxOfRing(ring);
  for (const f of [0.5, 0.25, 0.75, 0.125, 0.375, 0.625, 0.875]) {
    const y = b.minY + (b.maxY - b.minY) * f;
    const xs: number[] = [];
    for (let i = 0; i < ring.length; i++) {
      const p = ring[i]!;
      const q = ring[(i + 1) % ring.length]!;
      if ((p[1] > y) !== (q[1] > y)) xs.push(p[0] + ((y - p[1]) * (q[0] - p[0])) / (q[1] - p[1]));
    }
    xs.sort((m, n) => m - n);
    let best: Vec2 | null = null;
    let widest = 0;
    for (let k = 0; k + 1 < xs.length; k += 2) {
      const point: Vec2 = [(xs[k]! + xs[k + 1]!) / 2, y];
      if (xs[k + 1]! - xs[k]! > widest && pointInPolygon(point, ring, holes)) {
        widest = xs[k + 1]! - xs[k]!;
        best = point;
      }
    }
    if (best) return best;
  }
  return centroid;
}

export type StopPlan =
  | { ok: false; reason: string }
  | {
      ok: true;
      /** Null when the stop joins the same lift or stair on another floor. */
      portal: { id: string; kind: StopKind } | null;
      endpoint: {
        id: string; portalId: string; levelId: string; roomId: string; point: Vec2;
        footprint: Array<[number, number]>;
      };
      /** The space stays as the floor you step onto the stop from: open, and walkable. */
      roomPatch: { kind: "area"; walkable: true } | null;
    };

/**
 * What turning a traced space into a lift, escalator or stairs stop saves.
 *
 * The stop keeps the space's outline, so 3D builds a shaft or a flight from
 * it. It joins the portal of the same kind already stopping at this spot on
 * another floor, as the Lift or stair tool does. A portal of another kind
 * there is a different thing, so a new one is started.
 */
export function portalFromRoom(model: MapModel, room: Room, kind: StopKind, now = Date.now()): StopPlan {
  if (room.kind === "detail" || room.kind === "void") {
    return { ok: false, reason: "Only a room, area or service space can be a lift or stair stop." };
  }
  if (live(model.portalEndpoints).some(e => e.roomId === room.id && e.footprint)) {
    return { ok: false, reason: "This space is already a lift or stair stop." };
  }
  const placed = portalEndpointAt(model, room.levelId, insidePoint(room.footprint, room.holes), now);
  if (!placed.ok) return placed;

  const joinedKind = placed.portal ? null : live(model.portals).find(p => p.id === placed.endpoint.portalId)?.kind;
  const portal = placed.portal || joinedKind !== kind ? { id: `portal-${now}`, kind } : null;

  return {
    ok: true,
    portal,
    endpoint: {
      ...placed.endpoint,
      portalId: portal?.id ?? placed.endpoint.portalId,
      roomId: room.id,
      footprint: room.footprint.map(p => [p[0], p[1]] as [number, number]),
    },
    roomPatch: room.kind === "area" && room.walkable ? null : { kind: "area", walkable: true },
  };
}
```

```tsx
import { live, type Room } from "@oth/model";
import { useState } from "react";
import type { BuildStepId } from "../flow/floorProgress";
import type { Saver } from "../state/save";
import { useEditorStore } from "../state/store";
import { Button } from "../ui/Button";
import { toast } from "../ui/toast";
import { portalFromRoom, type StopKind } from "./portalFromRoom";

/** Names the drawing gives a lift or a flight of steps. */
const NAMED_LIKE_ONE = /^(escalators?|staircase|stairs?|lifts?|elevators?)\b/i;
const WORDS: Record<StopKind, string> = { lift: "Lift", escalator: "Escalator", stair: "Stairs" };

/**
 * Turns a traced space into a lift, escalator or stairs stop that keeps its
 * outline, so 3D builds a shaft or a flight from it (spec §7). Offered on
 * Entrances & lifts, and on any step for a space the drawing named like one.
 * That is how L1's "Escalator – nn" rooms are converted in the app.
 */
export function MakeStop({ saver, room, step }: { saver: Saver; room: Room; step: BuildStepId }) {
  const model = useEditorStore(s => s.model);
  const [busy, setBusy] = useState(false);

  if (!model || room.kind === "detail" || room.kind === "void") return null;
  if (step !== "entrances" && !NAMED_LIKE_ONE.test(room.nameEn.trim())) return null;
  if (live(model.portalEndpoints).some(e => e.roomId === room.id && e.footprint)) return null;

  async function make(kind: StopKind) {
    const current = useEditorStore.getState().model;
    if (!current) return;
    const plan = portalFromRoom(current, room, kind);
    if (!plan.ok) {
      toast({ message: plan.reason });
      return;
    }
    setBusy(true);
    try {
      // The same order, and the same way back, as placing a stop by hand (commitPoint).
      if (plan.portal && !(await saver.create("portal", plan.portal, { retry: false }))) return;
      if (!(await saver.create("portalEndpoint", plan.endpoint, plan.portal ? { retry: false } : undefined))) {
        if (plan.portal) await saver.remove("portal", plan.portal.id, 0);
        return;
      }
      if (plan.roomPatch) await saver.update("room", room.id, room.version, plan.roomPatch);
      toast({
        message: plan.portal
          ? `${WORDS[kind]} added. Switch level and click its dashed outline to add its next stop.`
          : "Joined the lift or stair already at this spot on another level.",
      });
    } finally {
      setBusy(false);
    }
  }

  return (
    <div className="space-y-2 border-t border-stone-200 p-3 text-xs text-stone-600">
      <p>Is this a lift, escalator or stairs? Choose which, and 3D builds it from this outline.</p>
      <div className="flex gap-2">
        {(["lift", "escalator", "stair"] as const).map(kind => (
          <Button key={kind} size="sm" disabled={busy} onClick={() => void make(kind)}>
            {WORDS[kind]}
          </Button>
        ))}
      </div>
    </div>
  );
}
```

```ts
/**
 * A one-page PDF around a raw content stream, for tests: the architect's
 * sheet never enters the repo (spec §9). ASCII only, so string length is
 * byte length and the xref offsets are right.
 */
export function minimalPdf(content: string, size: [number, number] = [600, 400]): Uint8Array {
  const objects = [
    "<< /Type /Catalog /Pages 2 0 R >>",
    "<< /Type /Pages /Kids [3 0 R] /Count 1 >>",
    `<< /Type /Page /Parent 2 0 R /MediaBox [0 0 ${size[0]} ${size[1]}] /Contents 4 0 R >>`,
    `<< /Length ${content.length} >>\nstream\n${content}\nendstream`,
  ];
  let out = "%PDF-1.4\n";
  const offsets: number[] = [];
  objects.forEach((body, i) => {
    offsets.push(out.length);
    out += `${i + 1} 0 obj\n${body}\nendobj\n`;
  });
  const xref = out.length;
  out += `xref\n0 ${objects.length + 1}\n0000000000 65535 f \n`;
  for (const offset of offsets) out += `${String(offset).padStart(10, "0")} 00000 n \n`;
  out += `trailer\n<< /Size ${objects.length + 1} /Root 1 0 R >>\nstartxref\n${xref}\n%%EOF\n`;
  return new TextEncoder().encode(out);
}
```

```ts
import type { Vec2 } from "@oth/model";

/** A proposal from the drawing, before B's worker turns it into a draft. */
export type Found = { nameEn: string; kind: "detail" | "area"; footprint: Vec2[]; labelPoint: Vec2; areaM2: number };

/** Drops repeated points and a closing point equal to the first. */
export function cleanRing(points: readonly Vec2[]): Vec2[] {
  const out: Vec2[] = [];
  for (const p of points) {
    const last = out[out.length - 1];
    if (!last || Math.hypot(p[0] - last[0], p[1] - last[1]) > 1e-6) out.push([p[0], p[1]]);
  }
  const first = out[0];
  const last = out[out.length - 1];
  if (out.length > 1 && first && last && Math.hypot(first[0] - last[0], first[1] - last[1]) <= 1e-6) out.pop();
  return out;
}

export const round2 = (n: number) => Math.round(n * 100) / 100;
```

```ts
import type { Vec2 } from "@oth/model";

export type PlanSubpath = { points: Vec2[]; closed: boolean };
/** A painted path from the drawing, in model metres, with its curves flattened. */
export type PlanPath = { subpaths: PlanSubpath[]; filled: boolean; stroked: boolean };

type Matrix = readonly [number, number, number, number, number, number];
const IDENTITY: Matrix = [1, 0, 0, 1, 0, 0];

/** `m` applied first, then `n`: how PDF's `cm` composes onto the current matrix. */
function multiply(m: Matrix, n: Matrix): Matrix {
  return [
    m[0] * n[0] + m[1] * n[2], m[0] * n[1] + m[1] * n[3],
    m[2] * n[0] + m[3] * n[2], m[2] * n[1] + m[3] * n[3],
    m[4] * n[0] + m[5] * n[2] + n[4], m[4] * n[1] + m[5] * n[3] + n[5],
  ];
}
const apply = (m: Matrix, x: number, y: number): Vec2 => [m[0] * x + m[2] * y + m[4], m[1] * x + m[3] * y + m[5]];

/** pdf.js 5+: each path is one Float32Array of these codes, each followed by its coordinates. Checked in Step 3. */
export const DRAW_OPS = { moveTo: 0, lineTo: 1, curveTo: 2, quadraticCurveTo: 3, closePath: 4 } as const;
const CURVE_STEPS = 8;

class PathBuilder {
  readonly subpaths: PlanSubpath[] = [];
  private current: PlanSubpath | null = null;
  private at: [number, number] = [0, 0];
  private start: [number, number] = [0, 0];

  constructor(private readonly ctm: Matrix, private readonly toModel: (pt: Vec2) => Vec2) {}

  private out(x: number, y: number): Vec2 {
    return this.toModel(apply(this.ctm, x, y));
  }

  get point(): [number, number] {
    return this.at;
  }

  moveTo(x: number, y: number) {
    this.current = { points: [this.out(x, y)], closed: false };
    this.subpaths.push(this.current);
    this.at = [x, y];
    this.start = [x, y];
  }

  lineTo(x: number, y: number) {
    if (!this.current) this.moveTo(this.at[0], this.at[1]);
    this.current!.points.push(this.out(x, y));
    this.at = [x, y];
  }

  curveTo(x1: number, y1: number, x2: number, y2: number, x3: number, y3: number) {
    const [x0, y0] = this.at;
    for (let i = 1; i <= CURVE_STEPS; i++) {
      const t = i / CURVE_STEPS;
      const s = 1 - t;
      this.lineTo(
        s * s * s * x0 + 3 * s * s * t * x1 + 3 * s * t * t * x2 + t * t * t * x3,
        s * s * s * y0 + 3 * s * s * t * y1 + 3 * s * t * t * y2 + t * t * t * y3,
      );
    }
  }

  quadTo(x1: number, y1: number, x2: number, y2: number) {
    const [x0, y0] = this.at;
    this.curveTo(x0 + (2 / 3) * (x1 - x0), y0 + (2 / 3) * (y1 - y0), x2 + (2 / 3) * (x1 - x2), y2 + (2 / 3) * (y1 - y2), x2, y2);
  }

  rect(x: number, y: number, w: number, h: number) {
    this.moveTo(x, y);
    this.lineTo(x + w, y);
    this.lineTo(x + w, y + h);
    this.lineTo(x, y + h);
    this.close();
  }

  close() {
    if (this.current) this.current.closed = true;
    this.current = null;
    this.at = this.start;
  }

  closeLast() {
    const last = this.subpaths[this.subpaths.length - 1];
    if (last) last.closed = true;
  }
}

function paintOf(op: number, OPS: Readonly<Record<string, number>>): { filled: boolean; stroked: boolean } | null {
  switch (op) {
    case OPS.stroke:
    case OPS.closeStroke:
      return { filled: false, stroked: true };
    case OPS.fill:
    case OPS.eoFill:
      return { filled: true, stroked: false };
    case OPS.fillStroke:
    case OPS.eoFillStroke:
    case OPS.closeFillStroke:
    case OPS.closeEOFillStroke:
      return { filled: true, stroked: true };
    default:
      // endPath and clipping paint nothing.
      return null;
  }
}

function readDrawOps(b: PathBuilder, data: ArrayLike<number>, draw: typeof DRAW_OPS) {
  for (let i = 0; i < data.length;) {
    const op = data[i++];
    if (op === draw.moveTo) {
      b.moveTo(data[i]!, data[i + 1]!);
      i += 2;
    } else if (op === draw.lineTo) {
      b.lineTo(data[i]!, data[i + 1]!);
      i += 2;
    } else if (op === draw.curveTo) {
      b.curveTo(data[i]!, data[i + 1]!, data[i + 2]!, data[i + 3]!, data[i + 4]!, data[i + 5]!);
      i += 6;
    } else if (op === draw.quadraticCurveTo) {
      b.quadTo(data[i]!, data[i + 1]!, data[i + 2]!, data[i + 3]!);
      i += 4;
    } else if (op === draw.closePath) {
      b.close();
    } else {
      // A code this does not know: stop rather than misread the rest as coordinates.
      return;
    }
  }
}

function readLegacyOps(b: PathBuilder, ops: readonly number[], c: readonly number[], OPS: Readonly<Record<string, number>>) {
  let j = 0;
  const next = () => c[j++]!;
  for (const op of ops) {
    switch (op) {
      case OPS.moveTo: b.moveTo(next(), next()); break;
      case OPS.lineTo: b.lineTo(next(), next()); break;
      case OPS.curveTo: b.curveTo(next(), next(), next(), next(), next(), next()); break;
      // "v": the first control point is the current point.
      case OPS.curveTo2: { const [x0, y0] = b.point; b.curveTo(x0, y0, next(), next(), next(), next()); break; }
      // "y": the second control point is the end point.
      case OPS.curveTo3: { const x1 = next(); const y1 = next(); const x3 = next(); const y3 = next(); b.curveTo(x1, y1, x3, y3, x3, y3); break; }
      case OPS.closePath: b.close(); break;
      case OPS.rectangle: b.rect(next(), next(), next(), next()); break;
    }
  }
}

/**
 * The drawing's painted paths, in model metres.
 *
 * It follows the current transform through q/Q, cm and form XObjects,
 * because CAD exports nest them. Text is not a path, so it never appears
 * here.
 */
export function pathsFromOperatorList(
  list: { fnArray: ArrayLike<number>; argsArray: ArrayLike<unknown> },
  OPS: Readonly<Record<string, number>>,
  toModel: (pt: Vec2) => Vec2,
  draw: typeof DRAW_OPS = DRAW_OPS,
): PlanPath[] {
  const paths: PlanPath[] = [];
  const stack: Matrix[] = [];
  let ctm: Matrix = IDENTITY;
  // pdf.js 4: a path waiting for the operator that paints it.
  let pending: PathBuilder | null = null;

  const finish = (builder: PathBuilder, op: number) => {
    const paint = paintOf(op, OPS);
    if (!paint || builder.subpaths.length === 0) return;
    if (op === OPS.closeStroke || op === OPS.closeFillStroke || op === OPS.closeEOFillStroke) builder.closeLast();
    paths.push({ subpaths: builder.subpaths, ...paint });
  };

  for (let i = 0; i < list.fnArray.length; i++) {
    const fn = list.fnArray[i]!;
    const args = (list.argsArray[i] ?? []) as unknown[];
    switch (fn) {
      case OPS.save:
        stack.push(ctm);
        break;
      case OPS.restore:
        ctm = stack.pop() ?? IDENTITY;
        break;
      case OPS.transform:
        ctm = multiply(args as unknown as Matrix, ctm);
        break;
      case OPS.paintFormXObjectBegin:
        stack.push(ctm);
        if (Array.isArray(args[0])) ctm = multiply(args[0] as unknown as Matrix, ctm);
        break;
      case OPS.paintFormXObjectEnd:
        ctm = stack.pop() ?? IDENTITY;
        break;
      case OPS.constructPath: {
        if (typeof args[0] === "number") {
          const builder = new PathBuilder(ctm, toModel);
          const data = (args[1] as ArrayLike<number>[] | undefined)?.[0];
          if (data) readDrawOps(builder, data, draw);
          finish(builder, args[0]);
        } else {
          pending ??= new PathBuilder(ctm, toModel);
          readLegacyOps(pending, args[0] as number[], args[1] as number[], OPS);
        }
        break;
      }
      default:
        if (pending && (paintOf(fn, OPS) !== null || fn === OPS.endPath)) {
          finish(pending, fn);
          pending = null;
        }
    }
  }
  return paths;
}
```

```ts
import { minAreaRect, ringArea, type BBox } from "@oth/model";
import type { PlanPath } from "./paths";
import { cleanRing, round2, type Found } from "./shapes";

/** Spec §7: small solid-filled rectangles, 0.3–1.5 m across. */
export const COLUMN_MIN_M = 0.3;
export const COLUMN_MAX_M = 1.5;
/** More than this many is hatching or a pattern, not a building's columns. */
export const COLUMN_LIMIT = 1500;

const inBox = (b: BBox, [x, y]: readonly [number, number]) => x >= b.minX && x <= b.maxX && y >= b.minY && y <= b.maxY;

/**
 * Columns, as the drawing fills them: a rectangle whose fill covers at least
 * 90% of its bounding box, or a near-square that covers at least 72% (a
 * circle covers 79%). What the second builder traced by hand for the west
 * concourse.
 */
export function findColumns(paths: readonly PlanPath[], within: BBox): { found: Found[]; note?: string } {
  const found: Found[] = [];
  for (const path of paths) {
    if (!path.filled) continue;
    for (const sub of path.subpaths) {
      const ring = cleanRing(sub.points);
      if (ring.length < 3) continue;
      const rect = minAreaRect(ring);
      const long = 2 * rect.halfLength;
      const short = 2 * rect.halfWidth;
      if (short < COLUMN_MIN_M || long > COLUMN_MAX_M) continue;
      const area = Math.abs(ringArea(ring));
      const cover = area / (long * short);
      const square = cover >= 0.9;
      const round = long / short <= 1.15 && cover >= 0.72;
      if (!square && !round) continue;
      if (!inBox(within, rect.centre)) continue;
      if (found.some(f => Math.hypot(f.labelPoint[0] - rect.centre[0], f.labelPoint[1] - rect.centre[1]) < 0.05)) continue;
      found.push({ nameEn: "Column", kind: "detail", footprint: ring, labelPoint: rect.centre, areaM2: round2(area) });
    }
  }
  if (found.length > COLUMN_LIMIT) {
    return { found: [], note: `Found ${found.length} small filled shapes: that is a pattern, not columns, so none were kept.` };
  }
  return { found };
}
```

```ts
import { distancePointToSegment, minAreaRect, pointInRing, rectCorners, ringArea, type Vec2 } from "@oth/model";
import type { PlanPath } from "./paths";
import { cleanRing, round2, type Found } from "./shapes";

export type SkippedLabel = { text: string; at: Vec2 };

/** An escalator or stair is 0.8–5 m wide and 2–30 m long in plan. */
const WIDTH_M: readonly [number, number] = [0.8, 5];
const LENGTH_M: readonly [number, number] = [2, 30];
/** A label printed beside its flight rather than on it. */
const LABEL_REACH_M = 2;

type Candidate = { corners: Vec2[]; centre: Vec2; area: number };

function distanceToRing(p: Vec2, ring: readonly Vec2[]): number {
  let best = Infinity;
  for (let i = 0; i < ring.length; i++) best = Math.min(best, distancePointToSegment(p, ring[i]!, ring[(i + 1) % ring.length]!));
  return best;
}

/**
 * The outline of each escalator and stair that Part B left out (spec §5.2),
 * taken from the smallest flight-sized rectangle holding its label, or else
 * the nearest one within 2 m. A label with neither is reported, so a person
 * draws that one by hand.
 */
export function findFlightOutlines(paths: readonly PlanPath[], labels: readonly SkippedLabel[]): { found: Found[]; missed: SkippedLabel[] } {
  const candidates: Candidate[] = [];
  for (const path of paths) {
    for (const sub of path.subpaths) {
      if (!path.filled && !sub.closed) continue;
      const ring = cleanRing(sub.points);
      if (ring.length < 4) continue;
      const rect = minAreaRect(ring);
      const long = 2 * rect.halfLength;
      const short = 2 * rect.halfWidth;
      if (short < WIDTH_M[0] || short > WIDTH_M[1] || long < LENGTH_M[0] || long > LENGTH_M[1]) continue;
      if (Math.abs(ringArea(ring)) / (long * short) < 0.85) continue;
      candidates.push({ corners: rectCorners(rect), centre: rect.centre, area: long * short });
    }
  }

  const used = new Set<Candidate>();
  const found: Found[] = [];
  const missed: SkippedLabel[] = [];
  for (const label of labels) {
    const holding = candidates
      .filter(c => !used.has(c) && pointInRing(label.at, c.corners))
      .sort((a, b) => a.area - b.area)[0];
    const chosen = holding ?? candidates
      .filter(c => !used.has(c))
      .map(c => ({ c, d: distanceToRing(label.at, c.corners) }))
      .filter(x => x.d <= LABEL_REACH_M)
      .sort((a, b) => a.d - b.d)[0]?.c;
    if (!chosen) {
      missed.push(label);
      continue;
    }
    used.add(chosen);
    found.push({
      nameEn: label.text, kind: "area", footprint: chosen.corners,
      labelPoint: holding ? label.at : chosen.centre, areaM2: round2(chosen.area),
    });
  }
  return { found, missed };
}
```
